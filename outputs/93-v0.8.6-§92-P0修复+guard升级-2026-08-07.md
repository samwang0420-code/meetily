## §62 A 多 daemon 核心设计 (决策)

```rust
// 旧: 单 daemon 串行
pub struct SherpaDaemon {
    inner: Mutex<Option<SherpaHandle>>,
}

// 新: N daemon round-robin
pub struct SherpaDaemon {
    inner: Vec<Mutex<Option<SherpaHandle>>>,
    counter: AtomicUsize,
    count: usize,
}
```

- **默认 count = 3** (8GB RAM sweet spot, 3 daemon × 700MB = 2.1GB)
- **env `MEETILY_SHERPA_DAEMONS=1..4`** 显式覆盖
- **round-robin**: `fetch_add(Relaxed) % count` — 不需要锁, 不需要严格时序
- **callers 零修改**: `global() / stream_begin / stream_chunk / stream_finalize / transcribe_blocking / capability / shutdown_blocking` API 不变
- **shutdown 关闭所有 N 槽**, 不只 slot 0
- **3 个新单测**: round_robin_wraps_within_pool / pool_count_is_n / next_slot_is_distributed_evenly
