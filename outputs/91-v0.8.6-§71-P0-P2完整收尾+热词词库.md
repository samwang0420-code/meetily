## 5 个阻塞 bug 修复

| Bug | 文件 | 修复 |
|---|---|---|
| 1. i18n 校验脚本路径编码 | `scripts/verify_i18n.mjs` | `file.pathname` → `fileURLToPath()` (跨平台 Windows/macOS) |
| 2. MCP server 写 DB 冲突 | `meetily-mcp/src/main.rs:132` | `SQLITE_OPEN_READ_ONLY` → `SQLITE_OPEN_READ_WRITE` (create_meeting_note / update_action_item 写操作必须) |
| 3. obsidian duration_seconds 算成一半 | `obsidian_export/mod.rs:394` | `f64::max(段差)` → `MAX(end_time)-MIN(start_time)` (段差会被静音段拖累) |
| 4. recording_devices emit 漏 meeting_id | `recording_commands.rs:502` | 加 `"meeting_id": meeting_id.clone()` 字段 |
| 5. action_items 永远拿不到行 | `action_items/mod.rs` | 从 JSON 路径改 markdown 表格解析 + 4 个 parser 单元测试 |

**Bug 1 根因**: 之前 `file.pathname` 在 macOS 上返回带空格的 path, Node.js require 失败; fileURLToPath 走的是真 URL 解码.
**Bug 5 根因**: 上游模板 `action_items` 输出格式从 JSON 改成 markdown 表格, 旧 parser 找不到.
