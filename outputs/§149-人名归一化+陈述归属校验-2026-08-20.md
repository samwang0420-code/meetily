## 2 个新函数

### `detect_attribution_confusion` (3 模式, 60 行)

1. **模式 1**: summary "被告人请求判处 X 年" / "被告人希望判处 X 年" → 量刑建议是辩护人/公诉人, 不是被告人本人诉求
2. **模式 2**: transcript 含被告人消极辩护原话 (如"觉得三年都太长, 只想回家"/"认罪悔罪"/"请求从轻") + summary 写"被告人请求判处" → 张冠李戴
3. **模式 3**: "法院判决" 而 transcript 实际是"公诉人量刑建议" (与 detect_fabricated_verdict 重叠, 跳过避免冗余)

### `normalize_name_drift` (40 行, 自动修复)

复用 `detect_name_drift` 找 drift pair, 选 transcript 中出现次数多的为 canonical, 把 summary 中的变体名替换为 canonical。

```rust
pub fn normalize_name_drift(transcript: &str, summary: &str) -> (String, Vec<String>) {
    // (归一化后 summary, 归一化操作列表)
    let drift_pairs = detect_name_drift(transcript, summary);
    // 选 transcript 中出现次数多的为 canonical
    let count_a = transcript.matches(a).count();
    let count_b = transcript.matches(b).count();
    let (variant, canonical) = if count_a >= count_b { (b, a) } else { (a, b) };
    if out.contains(variant) {
        out = out.replace(variant, canonical);
        normalized.push(format!("{} → {}", variant, canonical));
    }
}
```

**示例**: transcript 全用"李福强" (5 次), summary 含"李福强"和"李富强" → normalize 后 summary 全部统一为"李福强", ops = ["李富强 → 李福强"]
