# §110 SummaryPanel 按钮简化 — 9 按钮 → 4 元素 (2026-08-12)

## 触发

用户 8/12 截图反馈 (在 §109.1 恢复 TranscriptButtonGroup 之后):
> "你不觉得这部分的按钮太多了吗。提升审美, 让页面简洁好用, 不啰嗦"

附截图显示 summary 列顶部 9 个按钮横向挤在一起:
- 说话人名单 / 重新生成 / 自动检测 / AI 模型 / 模板 + 保存 / 复制 / 导出 MD / 导出 TXT

视觉感受: **按钮密度过高, 缺乏视觉层次, 像"华而不实"** (§104 §18 用户原则)

## 根因 (2 类)

### 类 1: 操作粒度太细
- 保存 / 复制 / 导出 MD / 导出 TXT 4 个按钮**都属于"导出"语义**, 没必要平铺
- 自动检测 / AI 模型 / 模板 3 个按钮**都属于"设置"语义**, 也是平铺

### 类 2: 标签冗长
- 每个按钮都有"图标 + 文字" (`lg:inline` 才显示文字), 横向 9 个就占满 1 行
- 没有视觉权重区分 (主操作=重新生成 不应该跟低频操作=查找 平级)

## 修复方案 (4 元素)

**核心思路**: 按使用频率 + 视觉权重重新分组, **主操作居左, 设置/导出收下拉**

```
[说话人名单]  [重新生成 ★]  [⚙️ 设置 ▾]  [📤 导出 ▾]
                              │              │
                              ├ 自动检测      ├ 保存
                              ├ AI 模型       ├ 复制
                              └ 模板          ├ 导出 MD
                                             ├ 导出 TXT
                                             └ 打开文件夹
```

**视觉变化**:
- 9 按钮 → 4 元素 (横向密度 -55%)
- 主操作 "重新生成" 仍带蓝紫渐变 (高亮)
- 设置 + 导出 收下拉 (按需展开)
- 整体布局: 左 (高频) + 右 (低频), 符合用户"简洁好用"要求

## 实现 (1 文件改)

### `frontend/src/components/MeetingDetails/SummaryPanel.tsx`

**imports 加**:
```tsx
import { DropdownMenu, DropdownMenuTrigger, DropdownMenuContent,
         DropdownMenuItem, DropdownMenuSeparator } from '@/components/ui/dropdown-menu';
import { Settings, Download, Sparkles, Save, Copy, FileCode, FileText, FolderOpen, FileType } from 'lucide-react';
```

**重构 button 区**:

```tsx
{aiSummary && !isSummaryLoading && (
  <div className="flex items-center justify-center w-full pt-0 gap-2">
    {/* 1. 说话人名单 — 独立 (触发 drawer) */}
    <Button ... onClick={() => setSpeakerDrawerOpen(true)}>
      <Users /> {t('speaker.title')}
    </Button>

    {/* 2. 重新生成 — 主操作 (蓝紫渐变) */}
    <Button ... onClick={onRegenerateSummary} disabled={isSummaryLoading}>
      <Sparkles /> {t('summary.regenerate')}
    </Button>

    {/* 3. ⚙️ 设置下拉 — 自动检测 / AI 模型 / 模板 */}
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <Button><Settings /> {t('summary.settings_title')} <ChevronDown /></Button>
      </DropdownMenuTrigger>
      <DropdownMenuContent>
        <DropdownMenuItem>{languageSlot}</DropdownMenuItem>
        <DropdownMenuSeparator />
        <DropdownMenuItem onClick={() => onOpenModelSettings?.(() => {})}>
          <Sparkles /> {t('summary.ai_model')}
        </DropdownMenuItem>
        <DropdownMenuItem onClick={() => onTemplateSelect(...)}>
          <FileType /> {t('summary.template')}
        </DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>

    {/* 4. 📤 导出下拉 — 保存 / 复制 / MD / TXT / 打开文件夹 */}
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <Button><Download /> {t('meeting_details.export_md')} <ChevronDown /></Button>
      </DropdownMenuTrigger>
      <DropdownMenuContent>
        <DropdownMenuItem onClick={onSaveAll}>
          <Save /> {t('summary.save')}
          {isDirty && <span className="ml-auto w-2 h-2 rounded-full bg-green-500" />}
        </DropdownMenuItem>
        <DropdownMenuItem onClick={onCopySummary}>
          <Copy /> {t('summary.copy')}
        </DropdownMenuItem>
        <DropdownMenuSeparator />
        <DropdownMenuItem onClick={onExportSummaryMarkdown}>
          <FileCode /> {t('summary.export_md')}
        </DropdownMenuItem>
        <DropdownMenuItem onClick={onExportSummaryTxt}>
          <FileText /> {t('summary.export_txt')}
        </DropdownMenuItem>
        <DropdownMenuSeparator />
        <DropdownMenuItem onClick={onOpenFolder}>
          <FolderOpen /> {t('meeting_details.open_folder')}
        </DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  </div>
)}
```

**SummaryGeneratorButtonGroup / SummaryUpdaterButtonGroup 文件保留** (其他场景可能用), 但在 SummaryPanel.tsx 不再调用。
