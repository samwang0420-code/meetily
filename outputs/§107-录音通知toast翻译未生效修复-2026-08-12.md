# §107 录音通知 toast 翻译未生效修复 (2026-08-12)

## 触发

用户 8/12 截图反馈: 录音通知 toast 显示英文 key 字面文本
```
recording.notification.title
recording.notification.body
recording.notification.dont_show
recording.notification.ack
```
而不是翻译后的中英文文案。预期中文: "🔴 录音已开始 / 请告知所有参会者..."

## 根因 (1 跳)

§104.1 (8/12 11:45 commit 090238c) 加 `localT('recording.notification.*')` 4 处调用 + i18n keys, 但实际把 4 个 key 放到了 `topbar.meeting_details.notification.*` 路径下。

```
recordingNotification.tsx:46,50,60,75 → localT('recording.notification.title|body|dont_show|ack')
zh.ts 实际声明位置:                   topbar.meeting_details.notification.{title,body,dont_show,ack}
```

`localT` 走到 lookup 失败 → fallback 返回 path 字符串本身 → 用户看到 `recording.notification.title` 字面。
