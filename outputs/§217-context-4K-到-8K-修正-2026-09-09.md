# §217 context 4K → 8K 修正 (2026-09-09)

## 触发

§215 (4K context) 改完后用户跑 1.5h 会议 (10,290 chars, ~7K tokens) 摘要失败:
```
meeting-c1299582 失败: chunk_count=0, error="Multi-level summarization failed: No chunks were processed successfully."
```

## 根因分析

§215 §52 §55 三处估算:
- chunk_transcript_by_token = 2400 tokens (§55)
- max_tokens = 800 (§52 BuiltInAI)
- prompt ≤ 600 tokens (§163)

理论 max = 2400 + 600 + 800 = **3800 ≤ 4096 ✓**

但实际中文会议 (10,290 字符 ~7,000 tokens, 中文 token/字符比 ~1.5):
- chunk 2400 tokens 准确
- 但 prompt 实际 ~800-1200 tokens (含 system + few-shot + §141 P141_VERBATIM_FACT_CHECK + §163 EVIDENCE_GROUNDED_SUMMARY_RULES 等多段硬规则)
- 实际 max = 2400 + 1200 + 800 = **4400 > 4096 ❌**

## 修复: 4K → 8K sweet spot

| Context | F16 KV | Q4_0 KV | 合计 vs 32K F16 |
|---|---|---|---|
| 32K | 1.28 GB | — | baseline |
| 8K | 0.32 GB | **0.08 GB** | **省 1.0 GB** (sweet spot) |
| 4K §215 | 0.16 GB | 0.04 GB | 省 1.24 GB (但不够用) |

Q4_0 KV @ 8K = 8 × 0.04 × 0.25 = 0.08 GB.

## §193 GPU layers @ 8K Q4_0

- vram = sysctl × 0.6 = 4.8 GB

- weight_per_layer = 53.6 MB (Q4_K_M 1.93GB / 36 layers)
