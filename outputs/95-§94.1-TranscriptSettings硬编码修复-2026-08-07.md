# §94.1 — TranscriptSettings 硬编码模型列表修复

**触发**: 2026-08-07 13:40 哥截图 — v0.8.6 已生效, 但 Transcript Model 下拉仍是 v0.7 W2.5 列表 (SenseVoice 23 段 / Paraformer 10 段 / Parakeet 旧推荐).

## 根因

`§90 commit fda59cd` 改了 `useTranscriptionModels.ts` hook (新 §90 决策列表: FunASR-Nano 947MB Pro + SenseVoice 228MB + Paraformer 216MB), 但**没改** `TranscriptSettings.tsx` 里硬编码的 SelectItem 列表.

**典型 "AGENTS.md § 章节 ≠ 代码" 案例** — §94 audit 检查了后端 Rust 代码 (retranscription.rs / useTranscriptionModels hook), 但漏了前端硬编码的 SelectItem 列表.

## §94.1 修复

### `frontend/src/components/TranscriptSettings.tsx`

#### 1. 第 1 个 Select (provider 选 2 个)

**Before** (W2.5 v0.7 硬编码):
```tsx
<SelectItem value="sherpa_funasr_nano">✨ SenseVoice-zh (推荐 · 23 段)</SelectItem>
<SelectItem value="sherpa_paraformer">🐉 Paraformer-zh (备选 · 10 段)</SelectItem>
<SelectItem value="parakeet">⚡ Parakeet (旧推荐 · 实测不如 SenseVoice)</SelectItem>
```

**After** (§90 决策 + 删 Parakeet):
```tsx
{/* §94.1 fix: §90 决策 - 2 个 provider, 第 2 个 Select 选具体 model name. §29 FunASR-Nano Pro gate 见 §94 P1. */}
<SelectItem value="sherpa_funasr_nano">✨ 本地 ASR (SenseVoice 228MB + FunASR-Nano 947MB Pro)</SelectItem>
<SelectItem value="sherpa_paraformer">🐉 Paraformer-zh 备选 · 216MB</SelectItem>
```

#### 2. modelOptions dict 删 parakeet (`§94.1 fix: parakeet v0.8+ 禁用`)

#### 3. 第二个 Select 漂亮名字 (model name → displayName)

**Before**: 直接显示 `model` 字符串 (e.g. `sense-voice-zh-int8`)

**After**:
```tsx
{/* §94.1 fix: 用 §90 决策文案, 不直接显示 model name */}
{modelOptions[uiProvider]?.map((model) => {
    const prettyName =
        model === 'funasr-nano-zh' ? '🧪 FunASR-Nano 高精度 · 947MB (Pro)' :
        model === 'sense-voice-zh-int8' ? '✨ SenseVoice-zh 推荐 · 228MB' :
        model === 'paraformer-zh-int8' ? '🐉 Paraformer-zh 备选 · 216MB' :
        model;
    return <SelectItem key={model} value={model}>{prettyName}</SelectItem>;
})}
```

#### 4. 196 行 描述修正 (23 段按句切 → 228MB)
