## 三、商业化剩余 / 必须做

### P0: 上架前必做 (内测期商业化闭环)

2. **应用商店上架物料** (App Store / 官网):
   - 应用名 + 副标题 + 5 张截图 + 1 分钟视频
   - 中文 + 英文双版本 (海外用 en, 国内用 zh)
   - 应用描述 / 隐私政策链接 / 用户协议链接
3. **支付通路** (C8-C10):
   - 拍脸车 (支付宝) — 国内主通路
   - 微信支付 — 国内备选
   - USDT — 海外/隐私优先用户
   - 当前仅激活码兑换 + 付邮 + 人工迁移, 不构成可持续商业化
4. **macOS 公证 + 签名分发**:
   - 当前 binary 是 `adhoc-signed`, 用户首次启动需右键打开
   - 需要 Apple Developer ID + 公证 (`notarytool`) 才能 Gatekeeper 通过
   - `.dmg` 安装包构建脚本 (`cargo-tauri bundle`)
5. **官网 + 落地页** (海外):
   - `stackmatrices.com` 模式 (SMMP 项目验证过)
   - Meetily 域名 (待定)
   - 下载链接 + 视频 + 5 截图
