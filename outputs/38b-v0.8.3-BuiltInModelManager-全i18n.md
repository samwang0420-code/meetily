# v0.8.3 §38 续 BuiltInModelManager + ModelSettingsModal 全 i18n (2026-07-31)

## 触发
用户截图设置页 "AI 总结模型" 区仍是英文:
- 标题 "AI 总结模型" + provider 下拉 "Built-in AI (Offline, No API needed)"
- 模型卡 "Qwen 3.5 2B (Balanced) ● Ready [Selected]"
- 描述 "Balanced Qwen 3.5 model for built-in summaries. Higher quality with modest local requirements."
- 元数据 "~1.2 GiB • 32768 tokens"
- "Download" 按钮

## 根因
BuiltInModelManager.tsx 已 import useTranslation (line 4 + line 50), 但整组件从未调用过 `t()`, 全是 hardcoded 英文. ModelSettingsModal.tsx 的 provider 下拉也有 2 条 hardcoded.

## 修复 (commit 51a9992)
### BuiltInModelManager.tsx (14 处)
1. "内置 AI 模型" → `t('summary.model_builtin_label')`
2. "No models found..." → `t('summary.builtin_ai_no_models')`
3. `model.display_name` → `getBuiltinModelDisplayName(t, model.name, fallback)` 通过 `BUILTIN_MODEL_I18N_KEYS` 映射
4. `model.description` → `getBuiltinModelDescription(t, model.name, fallback)` 同上
5. "Ready" → `t('summary.builtin_ai_ready')`
6. "Selected" → `t('summary.builtin_ai_selected')`
7. "Corrupted" → `t('summary.builtin_ai_corrupted')`
8. "Error" → `t('summary.builtin_ai_error')`
9. "Download" 按钮 → `t('summary.builtin_ai_download')`
10. "Cancel" 按钮 → `t('summary.builtin_ai_cancel')`
11. "Retry" 按钮 → `t('summary.builtin_ai_retry')`
12. "下载中..." → `t('summary.builtin_ai_downloading')`
13. "删除 model" tooltip → `t('summary.builtin_ai_delete_title')`
14. size label (~1.2 GiB / ~227 MiB) → `getBuiltinModelSizeLabel(t, mb)` 走 `builtin_ai_size_gib/mib`
15. "tokens" 后缀 → `t('summary.builtin_ai_tokens', { count })`
16. download progress "X MiB / Y MiB" / "(Z MiB/s)" → `t('summary.builtin_ai_download_progress', ...)` / `..._speed`

### ModelSettingsModal.tsx (2 处)
- `<SelectItem value="builtin-ai">Built-in AI (Offline, No API needed)</SelectItem>` → `{t('model_settings.builtin_ai_full')}`
- `<SelectItem value="custom-openai">Custom Server (OpenAI)</SelectItem>` → `{t('model_settings.custom_openai')}`

- `summary.builtin_ai_download_progress` / `..._speed`

## Rust 后端模型定义保留
`summary_engine/models.rs` 的 `display_name` / `description` 字段保留 (作为 fallback + 内部 telemetry), frontend 优先用 i18n key, i18n 找不到时 fallback. 不动 Rust 避免破坏 schema 兼容.
