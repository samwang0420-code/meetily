## 关键技术修复

### 1. TranscriptionProvider trait 包装 SherpaDaemon
```rust
// 离线性 audio 是 Vec<f32>,  daemon 要 base64 bytes
let mut bytes = Vec::with_capacity(audio.len() * 4);
for s in &audio {
    bytes.extend_from_slice(&s.to_le_bytes());  // f32 little-endian
}
let audio_b64 = base64_encode(&bytes);

// transcribe_blocking 是同步阻塞 IO,  必须 spawn_blocking
let result = tokio::task::spawn_blocking(move || {
    daemon.transcribe_blocking(&model, &audio_b64, 16000, false, "", "")
}).await
```

### 2. base64 编码手写
避免在 Cargo.toml 加 `base64 = "..."` 依赖 (binary size +1MB), 用 24 行手写:
```rust
const CHARSET: &[u8; 64] = b"ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/";
```

### 3. app.state() 需要 tauri::Manager trait
```rust
use tauri::Manager;
let state: tauri::State<crate::state::AppState> = app.state();
let pool = state.db_manager.pool();
```

### 4. TranscriptionEngine 4 个 match arm
```rust
// engine.rs (新增)
"Sherpa" => Some("sherpa-onnx (daemon)".to_string()),
"Self::Sherpa => \"Sherpa-onnx (daemon)\","

// worker.rs (4 处)
TranscriptionEngine::Sherpa => TranscriptionEngine::Sherpa,  // clone
TranscriptionEngine::Sherpa => 0.0,  // confidence threshold
TranscriptionEngine::Sherpa => { /* 调 SherpaProvider */ },  // 主 match
```

- modelload validation 在 worker 内 is_model_loaded() 永返 true (daemon lazy-start)
- realtimePreview 是前端 localStorage 开关, 还没接通后端 stop streaming
- modified_beam_search 在当前 sherpa-onnx 不可用 — 模型架构 non-autoregressive
