# §192 磁盘/内存清理 (2026-08-28)

## 触发
用户报告电脑存储和内存都被占满,需要排查清理。

## 现状 (清理前)
- 磁盘: 5.2GB 可用 / 228GB (98% 使用率)
- 内存: 8GB 物理 (Mac mini 8GB), PhysMem 7525M used, swap 持续吃紧
- 一个孤儿 cargo build 进程从 1:54PM 跑到 14:41 (47分钟), 还在 LTO 链接阶段

## 根因 (5 类)

### 1. 孤儿 cargo build (RAM 元凶)
- PID 61687 rustc --crate-name meetily 99% CPU + 1.14GB RAM
- 父进程 PID 56649 已死 (Codex CLI sandbox 关掉), 56650 cargo build --release 成孤儿
- rustc 在跑 LTO (`-C lto -C codegen-units=1`), 单 crate link time > 47min
- 释放: `kill -9 61687 56650`

### 2. target/debug/ 21GB
- 编译 debug 缓存 (build/ 2.9G + deps/ 13G + incremental/ 5.1G)
- 用户实际只用 release build, debug 全无用处
- AGENTS.md §21 已立 "debug-only 清理" 铁律, 从未执行

### 3. 老路径 meetily/models/ 465MB
- §97 identifier 改造 (cn.lixianhuiji.app → tech.yanjingai.app) 时漏删旧路径
- 含 `ggml-small.bin` 旧的 Whisper ggml 模型,用户已切到 sherpa

### 4. BitBrowser 1.5GB
- `Library/Caches/BitBrowser/` 防关联浏览器
- 用户已停用 (Apify 项目结束)

### 5. Codex 缓存 3.4GB
- `Library/Caches/com.openai.codex` 1.9GB
- `~/.cache/codex-runtimes` 1.5GB
- 运行时 cache, 自动重建

## 清理动作

```bash
# 1. 杀孤儿
kill -9 61687 56650

# 2. 备份 release binary (按 §89)
cp target/release/meetily /tmp/meetily.bak.$(date +%s)

# 3. target/debug/ 21GB
mv target/debug target/debug.TODELETE
find target/debug.TODELETE -type f -delete
find target/debug.TODELETE -depth -type d -empty -delete
rmdir target/debug.TODELETE

# 4. 老路径 meetily 465MB
mv ~/Library/Application\ Support/meetily ~/Library/Application\ Support/meetily.TODELETE
find ~/Library/Application\ Support/meetily.TODELETE -type f -delete
find ~/Library/Application\ Support/meetily.TODELETE -depth -type d -empty -delete
rmdir ~/Library/Application\ Support/meetily.TODELETE

# 5. BitBrowser 1.5GB
find ~/Library/Caches/BitBrowser -type f -delete
find ~/Library/Caches/BitBrowser -depth -type d -empty -delete

# 6. Codex caches 3.4GB
find ~/.cache/codex-runtimes -type f -delete
find ~/Library/Caches/com.openai.codex -type f -delete

# 7. /tmp 旧 backup
find /tmp/meetily.bak.1787845832 -type f -delete
rmdir /tmp/meetily.bak.1787845832
rmdir /tmp/target
```

## 新铁律 (§192 立)

1. **cargo build 必须有 timeout 保护** — `gtimeout 600 cargo build --release`, 防止再出现孤儿
2. **每月跑一次 debug 清理** — `mv target/debug target/debug.TODELETE && find ... -delete` (按 §21 强化版)
3. **§97 类迁移必须立即清旧路径** — 不能留 meetily/ 这种孤儿
4. **BitBrowser 等已停用 app Cache 列入每月清理清单**
5. **Codex cache 不主动清** (会自动重建, 除非用户显式要求)
