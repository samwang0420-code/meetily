## 修复 (5 项)

### 1. 数字差异强制标注 (§161 扩展)

`templates/legal_consultation.json` + `templates/court_hearing.json` description + 事实时间线 section 各加指令:
- 同一事件出现 ≥ 2 个数字时, **列出所有数字 + 来源** (现场称量/鉴定结论/起诉书/当庭陈述)
- 禁止只取一个数字隐瞒其他来源
- 例: "可卡因 9297 克 (起诉书指控) — 与警方现场初步描述 7900 余克存在表述差异"

### 2. 法律量刑背景强制补充 (新增 section)

**所有法律模板新增 "相关量刑背景 / Penalty Reference" section**, 必须列出:
- 涉案罪名的量刑门槛 (《刑法》第 XXX 条 verbatim)
- 涉案情形是否触发 + 严重程度

**常见罪名量刑门槛表** (内置):
- 走私/运输/贩卖毒品罪: 50 克 = 死刑门槛; 涉案 9000 克远超
- 故意伤害罪: 致人死亡 = 10 年以上/无期/死刑
- 交通肇事罪: 致 1 死 + 全责 = 3 年以下
- 盗窃/诈骗罪: 数额特别巨大 (50万+) = 10 年以上/无期

### 3. 零占位符铁律

**禁止**:
- "无明确律师建议内容"
- "无具体待办事项"
- "无遗留问题"
- "待人工确认"

**改为**: 缺失字段直接留空 (表格空 cell / 列表省略), 不写"无X"占位句

**案由强制 verbatim**: 必须从起诉书取, 禁止 "待人工确认". 没提到就完全省略该字段.

### 4. 证据表格 "可用性" 列规范

模板 instruction 明确:
- "已提供": transcript 明确说证据已提交/已出示
- "待提供": transcript 明确说"待提交/待补充"
- "未提及": transcript 没提可用状态 (≠证据不存在)
- **禁止**: 全填 "已提供" 凑数 / 全填 "未提及" 偷懒

## §18 / §37 / §56 / §92 铁律强化 (本节触发)

1. **template instruction 是根本**: LLM 严格按 instruction 输出, 模板允许"无明确X"兜底 → LLM 大量填占位符. 改模板, 不要事后过滤.
2. **法律背景常识必须 prompt 强制**: 不能指望 LLM 主动补充量刑门槛, 模板必须显式指令.
3. **ASR 错字字典要广**: 用户每次新报告一类, 就立刻扩展. 监事居留/监视居住 是高频法律术语.
