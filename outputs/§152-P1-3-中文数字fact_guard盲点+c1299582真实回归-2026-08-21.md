# §152 P1-3 中文数字 fact_guard 盲点 + c1299582 真实回归

## 触发事故
用户 28h 前生成的 c1299582 摘要出现 4 类严重 hallucination:
- "300 多万元" → transcript 实际 "三千余万元"
- "2016 年 7 月 11 日" → transcript 实际 "二零一四至二零一五年间"
- "诸暨市大唐小百货有限公司" → transcript 实际 "诸暨是大唐小百货公司" (法人代表名)
- 飞机事件错位塞到 2016 年 5 月

## 根因（已确认）

### 根因 1 — NUMBER_RE 盲点（致命）
`fact_guard.rs:9-30` 旧 NUMBER_RE 只匹配阿拉伯数字 + 单位（"3000万"）。
- transcript 中文数字 "三千余万元" 完全 miss
- summary "300 多万元" 同样 miss
- `unexpected_numbers` 永远为空 → 摘要通过 fact_guard

### 根因 2 — chunk 阶段 prompt 缺 P141
`processor.rs::build_chunk_summary_user_prompt` / `build_combine_summary_user_prompt` 用了 ENGLISH_BASE + EVIDENCE_GROUNDED + P1_PRECISION，但**没有 P141_VERBATIM_FACT_CHECK**（那是 final 才有）。
- chunk 阶段 LLM 改写数字后，事实已经错了
- reduce / final 拿到的事实本身就是错的 → 无法恢复

## 已落地修复

### 1. NUMBER_RE 加中文数字支持（`fact_guard.rs:9-30`）

新加第二条：
```
\d[\d,]*(?:\.\d+)?\s*(?:多)?\s*(?:元|块|万|亿|千|百万|千万|美元|人民币|dollars?)
```
（容忍 "300 多万元" 中 "多" 字）

新加第四条：
```
[零一二三四五六七八九十百千余几]+(?:[零一二三四五六七八九十百千余几 ]*)?\s*(?:余)?\s*(?:万|亿|百万|千万|千|万元|亿元|元人民币|美元|块|人民币)
```
（覆盖 "三千余万元" / "七百万" / "五万元" / "十块"）

**关键陷阱**：注释里不能有 `"`（即使在 raw string `r"(?x)"` 里也会截断字符串），要用中文或无引号。

### 2. chunk/combine prompt 加 P141（`processor.rs:316-330`）

`build_chunk_summary_user_prompt` 和 `build_combine_summary_user_prompt` 都加 `{P141_VERBATIM_FACT_CHECK}`，让 LLM 在 map 阶段就禁止改写数字/日期/人名/单位。

### 3. 5 个新单测

- `test_152_p1_3_chinese_numbers_detected` — 中文数字 hallucination 能被检测
- `test_152_p1_3_chinese_numbers_accepted` — verbatim 复用不误报
- `test_152_p1_3_chinese_units_extracted` — 验证提取器能识别 "三千余万元/七百万/五万元"
- `test_152_p1_3_c1299582_real_hallucination_caught` — **c1299582 真实 transcript 回归**，asserts:
  - hallucinated "300 多万元 / 2016 年 / 诸暨市大唐小百货有限公司" 必须被拦截
  - verbatim "三千余万元" 复用必须通过
