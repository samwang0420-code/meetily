# §170.8 multi-case 检测 regex 允许空白字符 (2026-08-24)

## 触发
用户截图反馈 §170.7 commit (e580668) 后"还是不行",多案件会议摘要仍显示 raw 内容,没有多案件 banner。

## 根因 (§170.7 仍然不生效)
后端 `serde_json::to_string` 缩进输出格式是:
```
[
  {
    "case_index": 1,
    ...
  },
  {
    ...
  }
]
```
即 `[` 后接 `\n  {`,不是紧凑 `[{`。前端 `detectSummaryFormat` Priority 1.5 用 `startsWith('[{')` 严格匹配,**字符串不以 `[{` 开头**(以 `[\n  {` 开头),条件 FALSE,触发不成立,fall through 到 Priority 2 markdown 检测,把 JSON 数组内容当 markdown 渲染。

## 修复 (commit 68b9443)
2 处检测从 `startsWith('[{')` 改为 regex `/^\[\s*\{/`:

1. `BlockNoteSummaryView.tsx:94` — `detectSummaryFormat` Priority 1.5
2. `SummaryPanel.tsx:102` — `detectMultiCaseSummary` (顶部 banner 显示判断)

```js
// 旧
if (trimmed.startsWith('[{')) { ... }
// 新
if (/^\[\s*\{/.test(trimmed)) { ... }
```

`\s*` 允许 `[` 和 `{` 之间任意空白(空格/换行/制表符)。

## Node 模拟验证
真实 serde 缩进格式 `"[\n  {\n"`:
- 旧 `startsWith('[{')`: **FALSE** ❌
- 新 `/^\[\s*\{/`: **TRUE** ✅
- detectMultiCaseSummary: `{ isMultiCase: true, caseCount: 2 }` ✅
