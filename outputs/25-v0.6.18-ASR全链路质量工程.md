# 离线会记 v0.6.18 ASR 全链路质量工程

日期：2026-07-16

## 本轮不是 UI 补丁

重新审计了模型配置、录音后重转写、VAD 分段、数据库刷新和质量反馈链路。

## 发现与修复

### 1. 模型配置不一致

- 前端默认配置曾是 `sensevoice-zh`。
- 模型选择列表和 worker 使用的是 `sense-voice-zh-int8`。
- 录音后重转写在 provider 缺省时，历史逻辑可能回到 Whisper。
- 现在前端默认模型和录音后批处理默认均统一到 `sherpa_funasr_nano / sense-voice-zh-int8`。

### 2. 最终文本刷新不完整

- 录音后重转写完成，会议页原来可能继续显示旧的实时草稿。
- 现在会议页监听 `retranscription-complete`，只在当前会议匹配时重新读取最终 transcript。

### 3. Streaming 尾段时间戳错误

- finalize 尾段以前固定为 `0.0` 秒。
- 现在记录当前录音最后音频位置，尾段写入真实末端附近时间，避免排序和回溯错误。

### 4. 加入可量化质量诊断

重转写完成事件现在返回：

- `speech_coverage`：VAD 检出的语音覆盖率；
- `transcript_chars`：识别文本字符数；
- `average_segment_seconds`：平均识别段长；
- `low_quality_warning`：覆盖率/文本密度异常时的警告。

弹窗会显示覆盖率和警告，不再只显示“转录完成”。

## 当前真实边界

这些修复让实际执行的模型、最终文本刷新、时间戳和质量观测一致，但不能凭代码证明中文识别准确率。必须使用真实音频比较：

1. 安静单人中文；
2. 多人会议；
3. 人名/金额/日期/专业术语；
4. 低音量或远场录音。

每次记录覆盖率、字符数、段数和人工标注错误，才能决定是否继续换模型或做更强音频前处理。
