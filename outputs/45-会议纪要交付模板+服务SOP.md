## 一、客户签约流程

### 第 1 步:意向确认(私聊)

参考 [[42-商业化方案-会议纪要外包+工具订阅]] 话术 D,目标:
- 确认客户有"会议跟进"痛点
- 确认客户愿意付费(¥1500-3000/月)
- 约定 30 分钟 1v1 视频(用腾讯会议 / Zoom,免费版即可)

### 第 2 步:需求摸底(1v1 视频,30 分钟)

**问 5 个问题**:
1. 你们团队每周开几场会议?(评估工作量)
2. 会议主要是跟谁开?(客户 / 红人 / 内部)
3. 现在怎么整理纪要?(助理 / 飞书妙记 / 没整理)
4. 纪要给谁看?(老板 / 全员 / 自己复盘)
5. 之前踩过什么坑?(数字记错 / 承诺忘跟 / 客户扯皮)

### 第 3 步:报价 + 试用

- **基础包 ¥1500/月**:每周 ≤ 5 场,每场 ≤ 60 min
- **标准包 ¥2000/月**:每周 ≤ 10 场,每场 ≤ 90 min
- **定制包 ¥3000+/月**:特殊需求
- **首月 8 折**:¥1200 / ¥1600,锁定 3 个月

**试用机制**:第 1 周散单 ¥99/场,客户体验后决定是否转月单。

### 第 4 步:签约

**微信签合同**(电子版):
- 服务范围:每周 X 场,每场 ≤ X min
- 价格:¥X / 月
- 周期:3 个月起签
- 支付:微信 / 支付宝 / USDT(月付)
- 终止:提前 7 天通知,无违约金

**不要签纸质合同**,太重,个人业务微信约定即可。

## 二、单场会议交付流程(从收到录音到交付)

### T+0(会议结束 30 分钟内):收到录音

**来源**:
- 客户自己录(系统内录 / 麦克风 / 手机录音 app)
- 你用离线会记帮客户实时录(需要客户授权)
- 第三方会议软件自动导出(Zoom / 腾讯会议下载)

**接收方式**:
- 微信发文件(≤ 100MB)
- 百度网盘 / 阿里云盘 / TG(> 100MB)
- 飞书文档附件

### T+0.5(收到后 30 分钟内):转录

**用离线会记 + 人工校对**:
1. 导入音频(mp3 / m4a / wav)
2. SenseVoice-zh 转录,自动标说话人
3. **人工校对**:把识别错误的数字 / 名字 / 术语改正(15-30 分钟)
4. **人工整理**:把流水账对话整理成结构化纪要

### T+2(收到后 2 小时内):整理纪要

**按下面模板**(见第三节)
- 关键信息:会议主题 / 时间 / 参与人
- 摘要:3-5 句话总结
- 待办清单:谁 / 做什么 / 何时
- 关键数字 / 承诺 / 异议点(标黄)
- 下次会议:时间 / 议题

### T+24(24 小时内):交付

**交付格式**:
- Markdown 文件(主交付)
- 微信消息(摘要 + 链接)
- 飞书文档链接(可选)

**交付话术**:
```
[客户名字] [会议主题] 纪要整理好了,见附件。

核心要点:
- [3-5 条 bullet,每条 1 行]
- 待办有 [N] 项,详见正文

有问题随时说,下次会议 [时间] 见。
```

## 四、质量自查 Checklist(每次交付前)

- [ ] **数字 100% 准确**:金额 / 数量 / 时间 / 邮箱 / 微信号 — 必须 0 错误
- [ ] **名字 100% 准确**:客户名 / 红人名 / 公司名 — 必须 0 错误
- [ ] **待办清单完整**:每场会议必须 ≥ 3 条待办,否则说明会议没成果

## 五、客户沟通规范

### 响应时效

| 场景 | 响应时间 |
|---|---|
| 工作时间(9:00-22:00) | 30 分钟内 |
| 会议中实时问题 | 即时 |
| 紧急会议纪要(2h 内交付) | 1 小时内 |
| 非工作时间 | 24 小时内 |

### 红线

- ❌ **不接客户实时对话窗口**:除非是工具使用问题,纯会议跟进不接
- ❌ **不参与客户内部决策**:只整理会议,不做策略建议
- ❌ **不替客户做判断**:数字 / 风险如实记录,不下结论
- ❌ **不向第三方透露**:客户会议内容严格保密,朋友圈不写客户名

### 加分项

- ✅ 主动发现客户没说的事:"您刚才说的 X 没在会上,我帮您标了,需要下次补充吗?"
- ✅ 主动跟进待办:"李四的待办是 7/18,目前没收到,需要我提醒吗?"
- ✅ 主动对比上次会议:"上次客户说 ¥2000,这次改成 ¥1500,我标黄了,需要您确认"

## 六、产能上限与扩张

### 单人产能

- 转录 + 校对 1 小时会议:**1-1.5 小时**(60% 校对)
- 整理纪要:**30-45 分钟**
- 交付 + 沟通:**15 分钟**
- **单场总工时**:2-2.5 小时

**单人周产能**(假设每天 8 小时工作):
- 标准包 10 场/周 = 25-30 工时 → **饱和**
- 实际建议:**最多 8 场/周**(留 20% 缓冲)

### 突破产能

#### 第一步(M2 启动):招 1 个兼职助理

- 招聘渠道:TG 群 / 朋友圈 / 豆瓣小组
- 时薪:**¥50/h**(刚开始,熟练后 ¥60-80)
- 工作内容:转录校对 + 纪要整理
- **培训**:2-3 天(用你自己的工具 + SOP)
- **成本**:10 场/周 = ¥1500-2000/月

#### 第二步(M3 启动):标准化

- 纪要模板沉淀(每种会议类型:客户谈判 / 红人沟通 / 内部周会)
- 校对 Checklist 化(让助理不需要问你)
- 客户沟通话术化(常见问题 FAQ)

#### 第三步(M4+ 启动):涨价 + 拓客

- 单价从 ¥2000 → ¥3000(产能饱和涨价)
- 老客户转介绍(¥200 / 单返利)
- 内容获客(小红书 + 知乎)

## 七、计费与对账

### 月度账单

```
客户:[名字]
服务周期:2026-08-01 ~ 2026-08-31
本月会议数:X 场
服务费:¥X(基础包 / 标准包 / 定制包)
超量:X 场 × ¥Y/场 = ¥Z
合计:¥X + ¥Z = ¥TOTAL

收款方式:微信 / 支付宝 / USDT
收款时间:每月 1 日
```

### 超量收费

- 基础包超量:¥80/场
- 标准包超量:¥60/场
- 定制包:无超量费(本身配额大)

### 退款规则

- 月度内退款:**剩余天数 × 单日价**(扣除已服务天数)
- 客户原因终止:**不退款**(已服务部分不退款,剩余可协商)
- 我方原因终止:**全额退款**

## 八、风险预案

### 工具故障

**应对**:保留备用工具
- Whisper Desktop(开源,英文 OK 中文凑合)
- 通义听悟 / 飞书妙记(在线,1-2 小时救急)
- 人工转录(最后兜底,找速录 ¥200/小时)

### 客户跑单

**应对**:
- 月付,沉没成本低
- 3 个月起签,降低跑单概率
- 关键会议前收预付款 ¥500

### 自己过载

**应对**:
- 单周 > 12 场 → 暂停接新客户
- 主动跟现有客户沟通延期
- 招助理(见 §6)

### 客户涉敏

**应对**:
- 签约前明确边界(见 [[42-商业化方案-会议纪要外包+工具订阅]] 红线)
- 涉敏项目不接
- 接了发现涉敏 → 立即终止,全额退款
