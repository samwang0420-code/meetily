## 根因 3 处
1. **ConfigContext 默认 model 是 paraformer-zh (227MB 轻量)**, 但 Settings 下拉 label 标 "默认·高精度" — 自相矛盾, 用户无法开箱即用高精度.
2. **HomeDashboard.modelLabel**: 在 `sherpa_funasr_nano + paraformer-zh` 走 `model_paraformer` 轻量 label, 跟 provider label 「高精度」反向.
3. **TranscriptSettings 蓝框误导** + Parakeet 选项遗留.

## 修复 (commit 3104d82)
- `frontend/src/contexts/ConfigContext.tsx`:
  - 默认 `model: 'paraformer-zh'` → `'funasr-nano-zh'` (994MB 真高精度)
  - 老用户 DB 里 `paraformer-zh` 也升级 (`is_legacy_model` 列表加一项)
- `frontend/src/app/_components/HomeDashboard.tsx`:
  - `modelLabel` 改 provider-first: `sherpa_funasr_nano` → 「FunASR-Nano 高精度」, `sherpa_paraformer` → 「Paraformer-zh 轻量」
- `frontend/src/components/TranscriptSettings.tsx`:
  - 删 Parakeet 下拉项 (`<SelectItem value="parakeet">`)
  - 蓝框文案重写: 按精度排序列出已装模型 (✨ FunASR-Nano 994MB / 🐉 Paraformer-zh 227MB), 加「未安装模型不显示」说明
- `frontend/src/i18n/locales/{zh,en}.ts`: 删 `model_sensevoice` key
