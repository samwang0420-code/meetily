# §109 会议详情页 UI 整理 — 2 个 i18n key 错 + TranscriptButtonGroup 重复 (2026-08-12)

## 触发

用户 8/12 截图反馈 "页面有点乱":
- 顶部两套重复工具栏挤在一起 (transcript 列浅色 + summary 列深色)
- Speaker Roster 按钮显示英文 key `common.speaker_title_short` 字面
- "录音" 按钮错位 — 实际功能是打开录音文件夹

## 根因 (3 个独立 bug)

### Bug 1: Speaker Roster 按钮 i18n key 错
- `SummaryPanel.tsx:334` 用 `t('common.speaker_title_short')`
- i18n 实际声明: `speaker.title` (zh: '说话人名单', en: 'Speaker roster')
- `common.speaker_title_short` 在 i18n 中**不存在** → fallback 返回 path 字符串
- 同 §107 一样的 i18n 路径错位 bug (§56 教训)

### Bug 2: "录音" 按钮 label 错
- `TranscriptButtonGroup.tsx:101` 用 `t('meeting_details.recording')` 显示 button label
- 但实际 onClick 是 `onOpenMeetingFolder` (打开录音文件夹)
- i18n `meeting_details.recording` = `'录音'` (用于 sidebar "录音" 导航)
- 应该用 `meeting_details.open_folder` = `'打开录音文件夹'`

### Bug 3: 顶部两套工具栏重复
- `TranscriptPanel` (左列 1/3) 顶部渲染 `<TranscriptButtonGroup>`: 复制转录 / 导出 MD / 导出 TXT / 打开录音文件夹 / 重新转录
- `SummaryPanel` (右列 2/3) 顶部渲染 `<SummaryGeneratorButtonGroup>` + `<SummaryUpdaterButtonGroup>`: 重新生成 / 语言 / AI 模型 / 模板 + 保存 / 复制 / 导出 MD / 导出 TXT / 查找 / 打开文件夹
- **复制 / 导出 MD / 导出 TXT / 打开文件夹 4 个按钮重复出现** — 用户看到两套, 觉得"乱"
- 与 §104 "华而不实" 用户原则一致, transcript 列顶部工具栏应隐藏

### 3. `frontend/src/components/MeetingDetails/TranscriptPanel.tsx` — 隐藏 TranscriptButtonGroup

```tsx
// 改前
<div className="p-4 border-b border-gray-200">
  <TranscriptButtonGroup ... />
</div>

// 改后 ({false && (...)} 隐藏整个块, 保留 props 链路 git log 还原)
<div className="p-4 border-b border-gray-200">
  {false && (
    <TranscriptButtonGroup ... />
  )}
</div>
```

**为什么用 {false && ...} 不用注释掉 JSX**:
- 保留 props 链路 (transcriptCount / onCopyTranscript 等 prop 仍传入)
- 未来想恢复时只需 `git log` 找 §109 还原 `{false && ...}` 包裹
- 不影响 linter / TS 类型 (false 表达式是合法 JSX)
