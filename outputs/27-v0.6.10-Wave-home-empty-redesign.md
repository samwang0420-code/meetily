# v0.6.10 工作台空白状态重设计 (2026-07-10)

## 用户反馈
没录音时, 工作台整片空白 (`<TranscriptPanel />` 没数据 = 空), 只有右下一个小欢迎 + 红 mic 按钮。视觉浪费、交互无引导, 5 条历史会议藏在 sidebar 底部看不出。

#### 数据源
- `indexedDBService.getAllMeetings()` → `MeetingMetadata[]`(倒序取前 6)
- `useConfig().transcriptModelConfig.provider` → 转录模型名
- `useConfig().selectedDevices.micDevice` → 当前麦克风

#### 视觉特性
- `motion.section` framer-motion 渐入, 4 区域依次 stagger (delay 0, 0.05, 0.1, 0.15)
- max-w-6xl 居中容器, 背景 `bg-gradient-to-b from-neutral-50 to-white`
- 卡片 hover: `hover:-translate-y-0.5` + `hover:shadow-sm` + `hover:border-neutral-300`
- 录音中 / 处理中 → return null(让 TranscriptPanel 接替)

### 重构 `frontend/src/app/page.tsx`

**主区条件化**:
```tsx
<div className="flex flex-1 overflow-hidden">
  {recordingState.isRecording ? (
    <TranscriptPanel ... />
  ) : (
    <HomeDashboard ... />
  )}
</div>
```

录音中走 TranscriptPanel + 底部药丸老逻辑; 默认未录音态走 HomeDashboard。

## 边界
- `getAllMeetings` 默认只返 unsaved(savedToSQLite=false), 首批用户刚装的可能没数据, 显示空状态 OK
- 用 `MeetingMetadata.transcriptCount` 估算时长≈count×4秒(粗估), 不精确但能看
- micDevice 字段可能为 null, 显示"默认输入设备"占位
- showModal 用了 type-skip 的 string 转换, 因为现有 `useModalState` 类型较严
