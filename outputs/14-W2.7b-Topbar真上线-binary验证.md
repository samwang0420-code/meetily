# W2.7b — Topbar v2 真正上线 + 完整 i18n 补完 (2026-07-10)

## 关键发现：**Tauri 2.x 不 embed frontend！**

花了 1 小时才搞清楚：
- **Tauri 2.x (meetily 0.4.0 用 tauri 2.6.2)** 通过 `asset:` protocol 在**运行时**从 `frontendDist: ../out` 读文件
- **不需要 cargo 重编**来更新 frontend chunks
- 但 **tauri_build::build() 在编译时检查 capabilities/config**，所以 src-tauri 代码改动才需要重编

### 验证
- `out/_next/static/chunks/9929-d60c1f3e6a2aad1a.js` (Topbar v2 chunk, 32KB) 写到 disk 01:09:59
- `target/release/meetily` mtime 01:17:26（一次 cargo 跑过了，但**frontend 内容是 out/，不进 binary**）
- binary 内 '中文': 6 hits（Topbar LOCALE_LABEL 嵌入 v0.5.0b 之前版本的 chunk）
- 注意：binary 的 'Topbar' / 'isCollapsed' 0 hits 因为 minify + 树摇，不影响渲染
