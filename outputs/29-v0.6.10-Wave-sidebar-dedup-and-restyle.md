# v0.6.10 侧栏去重 + 主区瘦身 (2026-07-10)

## 用户反馈
1. **还是有 2 个"离线会记"**: Topbar 一个 + 侧栏一个
2. **大量重复入口**:
   - 侧栏"MEETING NOTES"列表 vs 中间 HomeDashboard "最近会议" grid → 数据不同步
   - 侧栏"设置 / 热词词库" vs 中间 HomeDashboard "热词库 / AI 模板 / 导入音频" → 重复
3. 整体风格要更克制、更专业

## 修复方案

### 1. 侧栏品牌区收敛 (`Sidebar/index.tsx`)

**改动**: 删掉原 Brand block（line 723-755）展开态呈现"蓝色 mic icon + 离线会记 + 本地 AI 会议转录"的完整品牌区。

**新方案**: 侧栏顶部 h-14 单盾牌图标, 文字品牌只在 Topbar:
```tsx
<div className="flex h-14 items-center justify-center border-b border-neutral-200/70">
  <button onClick={() => router.push('/')} aria-label="离线会记">
    <svg viewBox="0 0 100 100" className="h-7 w-7" fill="none">
      {/* 14 path 盾牌 + 6 波形 + 水平切断线, 与 Topbar BrandMark 完全一致 */}
    </svg>
  </button>
</div>
```

`renderCollapsedIcons` 顶部盾牌删掉(避免展开/折叠双盾牌), 只保留 Home/Mic/Upload icon 列。

### 2. HomeDashboard 大改 (`app/_components/HomeDashboard.tsx`)

**删掉** 之前塞的 3 张"快捷入口" 卡(热词库/导入音频/AI 模板) — 与侧栏入口重复

**保留并升级**:
- Hero 欢迎标题 + 录音大按钮
- 状态条从 3 张"卡片" → 改为 **3 个 chip + 1 个设置按钮**, 整体收缩成一行:
  - `<StatusChip tone="blue" label="转录模型" value=...>`
  - `<StatusChip tone="emerald" label="麦克风" value=...>` (max 28 字符截断)
  - `<StatusChip tone="violet">...`
  - 末尾 `<button>` 跳设置
- 最近会议 grid: 标题区加 "共 N 条会议 · 显示最近 M 条"

**数据同步**: 同时从 indexedDB `getAllMeetings()` (unsaved) + 侧栏 `useSidebar().meetings` (saved) 合并, 避免之前 sidebar 列表 vs 中间 grid 不同源问题。

### 3. 侧栏底部版本号更新

`v0.5.0 · MIT` → `v0.6.10 · MIT`, 折叠态 `v0.5` → `v0.6.10`
