## 根因 (1 跳)

macOS `localhost` DNS 解析同时返 IPv6 (`::1`) 和 IPv4 (`127.0.0.1`):

```
curl -v http://localhost:11434/api/tags
* Host localhost:11434 was resolved.
* IPv6: ::1
* IPv4: 127.0.0.1
* Trying [::1]:11434 → Connection refused
* Trying 127.0.0.1:11434 → Connected → 200 OK
```

curl `happy_eyeballs` 成功 fallback,但 **reqwest client 在 macOS 默认走 IPv6 优先,3s timeout 内 IPv6 connection refused 后**:
- 要么直接返回 error (没有给 IPv4 机会)
- 要么超时导致整个 request fail

`preflight_ollama_async` (3s timeout) → "ollama unreachable" → emit `topic-recover-skipped` → UI 显示 banner → `extract_missing_topics` 立刻 return (0, 0) → **trigger_after_summary 永远不跑** → 所有历史会议 episode=0
