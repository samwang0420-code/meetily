# §114 React 渲染错误不再弹红色 toast (2026-08-13 立)

> **触发**: 用户截图显示录音停止后弹绿色 "Recording saved successfully! 0 transcript segments saved." + 红色 "保存会议失败 (UI 渲染时出错, 已隔离该会议卡; 控制台查看堆栈)" 双 toast。
> **根因**: CardBoundary 已隔离渲染错误 + 渲染 fallback 占位卡, 但 useRecordingStop catch 块再 toast 一次 → 双重告警。
> **修复**: React 内部错误 (`Minified React error #\d+`) 仅 console.warn, 不弹红色 toast。

## 1. 截图实证 (2026-08-13 10:00)

```
绿色 toast: Recording saved successfully! 0 transcript segments saved.
红色 toast: 保存会议失败 (UI 渲染时出错, 已隔离该会议卡; 控制台查看堆栈)
```

两个 toast 同时出现，让用户困惑"录音到底成功没"。

## 2. 根因链 (3 跳)

1. **CardBoundary** (`frontend/src/app/_components/CardBoundary.tsx`) 已正确隔离：
   - 失败时渲染红色 "渲染失败" 占位卡
   - 整张 main 树不崩
   - fallback 卡仍可点击（虽然不跳转）
2. **useRecordingStop** (`frontend/src/hooks/useRecordingStop.ts:472`) catch 块：
   - 检测到 `Minified React error #\d+` 模式
   - 弹红色 toast 显示"已隔离"提示
3. **问题**：CardBoundary 已经隔离 + 用户看到"已隔离"提示 = 二次告警

## 3. 修复 (1 文件)

### `frontend/src/hooks/useRecordingStop.ts`

修复前:
```typescript
} catch (saveError: any) {
  console.error('[useRecordingStop] save meeting failed', saveError);
  const msg = saveError instanceof Error ? saveError.message : String(saveError || 'Unknown error');
  const isReactInternal = /Minified React error #\d+/.test(msg);
  const friendly = isReactInternal
    ? '保存会议失败 (UI 渲染时出错, 已隔离该会议卡; 控制台查看堆栈)'
    : msg;
  setStatus(RecordingStatus.ERROR, sanitizeDescription(msg, 'error'));
  try {
    safeToast.error('保存会议失败', {
      description: friendly,
      duration: 8000,
    });
  } catch {}
}
```

修复后:
```typescript
} catch (saveError: any) {
  // §114: React 内部错误已被 CardBoundary 隔离, 不再弹红色 toast (重复打扰)
  // 实际后端错误 (非 React 内部) 才弹 toast
  console.error('[useRecordingStop] save meeting failed', saveError);
  const msg = saveError instanceof Error ? saveError.message : String(saveError || 'Unknown error');
  const isReactInternal = /Minified React error #\d+/.test(msg);
  if (isReactInternal) {
    // React 内部错误: CardBoundary 已隔离 + 渲染 fallback 占位卡 (红色 "渲染失败" 标记)
    // 这里只 log, 不弹 toast (避免双告警). 用户看到的"录音保存成功"绿色 toast 是真实状态.
    console.warn('[§114] React 渲染错误已被 CardBoundary 隔离, 不弹红色 toast');
    console.warn('[§114] 错误详情:', msg);
  } else {
    // 实际错误 (后端失败 / 网络断 / db 写失败等), 弹 toast 提示用户
    setStatus(RecordingStatus.ERROR, sanitizeDescription(msg, 'error'));
    try {
      safeToast.error('保存会议失败', {
        description: msg,
        duration: 8000,
      });
    } catch {}
  }
}
```

## 4. 行为对比

| 场景 | 修复前 | 修复后 |
|---|---|---|
| 录音成功 + 某会议卡渲染失败 | 绿 toast + 红 toast 双告警 | 绿 toast + console.warn（用户不被打扰） |
| 录音成功 + 所有会议卡 OK | 仅绿 toast | 仅绿 toast |
| 录音失败（后端 / DB） | 红 toast 显示实际错误 | 红 toast 显示实际错误（不变） |
| CardBoundary 隔离 fallback | 红色 "渲染失败" 占位卡 | 红色 "渲染失败" 占位卡（不变） |
