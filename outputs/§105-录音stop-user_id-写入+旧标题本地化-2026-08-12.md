# §105 录音 stop user_id 写入 + 旧标题本地化 (2026-08-12)

## 触发

用户 8/12 反馈：
1. 录音结束后弹"保存会议失败 (UI 渲染时出错, 已隔离该会议卡; 控制台查看堆栈)"
2. Sidebar 显示 "Recording in progress (Untitled)" 英文
3. 会议数据**实际保存成功**（103 段 / 2359 chars），但 user_id = NULL

## DB 实证

```sql
sqlite3 ~/Library/Application\ Support/tech.yanjingai.app/meeting_minutes.sqlite \
  "SELECT id, user_id, title FROM meetings ORDER BY created_at DESC LIMIT 5"

# meeting-7b9ddbb7-... | NULL | "Recording in progress (Untitled)"
# meeting-e5142702-... | 2    | "导入音频 2026-08-11 09:49"
# meeting-f2b73add-... | 2    | "导入音频 2026-08-05 13:45"
```

103 段 transcripts 数据 OK, 但 user_id 漏写, 标题是英文 placeholder。

## 根因 (3 个)

1. **`recording_commands.rs:240/410`** placeholder INSERT 没写 `user_id` 列
   - `INSERT INTO meetings (id, title, created_at, updated_at, folder_path) VALUES (?, ?, ?, ?, ?)`
   - 5 列, 这是 v0.7.1 早期 schema, 缺 user_id

2. **`api/api.rs:986` save_transcript** 调 `TranscriptsRepository::save_transcript` 也没传 user_id
   - import 路径 §99 已修, 但录音 stop 路径漏修

3. **英文标题 "Recording in progress (...)"** 硬编码在 Rust, 前端渲染时直接 DB title
   - 没走 i18n, 中文界面显示英文
   - 这个英文标题其实是个 bug — 是 placeholder, 录音 stop 时会被新 title 覆盖
   - 但 i18n 路径断掉, 即使覆盖也可能显示"Untitled" 等

## 修复 (5 文件)

### 1. `frontend/src-tauri/src/audio/recording_commands.rs`
- 加 `use crate::user::commands::latest_session_in_db;`
- 2 处 placeholder INSERT 改:
  - 标题直接存 `meeting_name.unwrap_or("Untitled")` (i18n 在前端处理)
  - 加 `user_id` 列, 从 `latest_session_in_db` 拿
  - 调试日志加 `user_id={:?}`

### 2. `frontend/src-tauri/src/database/repositories/transcript.rs`
- `save_transcript` signature 加 `user_id: Option<i64>` 参数
- INSERT meetings SQL + `user_id` bind

### 3. `frontend/src-tauri/src/api/api.rs`
- `api_save_transcript` 调用前先 `latest_session_in_db(&_app)` 拿 user_id
- 传给 save_transcript

### 4. `frontend/src/components/Sidebar/index.tsx`
- 加 `meetingTitle(raw: string)` helper:
  - 如果 raw 是空 / "Untitled" / "Recording in progress (...)" → 返回 i18n `meeting.untitled`
  - 否则返回 raw
- 2 处 `item.title` 渲染改用 `meetingTitle(item.title)`

### 5. `scripts/check_historical_fixes.py`
- 121 → 128/128 PASS (4 §105 锚点: save_transcript user_id / placeholder Untitled / api_save_transcript user_id / sidebar helper)
