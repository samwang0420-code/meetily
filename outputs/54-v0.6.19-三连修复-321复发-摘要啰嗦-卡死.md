## 修复 1: #321 复发根因
safeToast 全局防御已上 ([53-v0.6.18-React-321-根治-safeToast]), 但**真凶不在 toast**,
而在 useMeetingData / useSummaryGeneration / useRecordingStop 把 error.message
(可能含 "Minified React error #321; visit https://react.dev/errors/321 ...")
塞进 React state, 下次组件渲染时 <div>{error}</div> 让 React reconciler 再炸一次.

**修法**: 所有 setError / setSummaryError / setStatus(RecordingStatus.ERROR, ...) 调用前
用 sanitizeDescription 把 React error 字面降级为中文 fallback.

### 改动
- `useMeetingData.ts:6` 加 `sanitizeDescription` import
- `useMeetingData.ts:70, 114` `setError(error.message)` → `setError(sanitizeDescription(error.message))`
- `useSummaryGeneration.ts` 加 `sanitizeDescription` import
- `useSummaryGeneration.ts:230` `setSummaryError(errorMessage)` → sanitize
- `useRecordingStop.ts:475, 494` `setStatus(RecordingStatus.ERROR, msg/...)` → sanitize

## 修复 2: 摘要啰嗦
法律模板原 9 段 (案件与会议信息 / 当事人主张与答辩 / 已确认事实与待核实事实 /
争议焦点 / 证据与材料 / 程序节点与期限 / 会议形成的法律意见 / 待办事项 / 风险与待确认问题),
每段都填得满满, 截图里 4 屏都看不完.

**修法**: 精简到 5 段 (基本事实 / 当事人主张 / 律师建议 / 待办事项 / 遗留问题),
每段 instruction 加"≤ N 字 / 缺失写未提及 / 禁止猜测"硬约束, 模板名从"法律诉讼纪要"改"法律咨询纪要" (非庭审).

### 改动
- `frontend/src-tauri/templates/legal_consultation.json`: 9 段 → 5 段, 名称改"法律咨询纪要"

## 修复 3: 卡死
polling 间隔 5s 太慢, polling 完成时 BlockNoteSummaryView 内部 useEffect
依赖  引用变化, 但父组件 aiSummary state 同步有时序差,
导致"切走再切回"才看到摘要.

**修法**:
1. Polling 间隔 5s → 2s (MAX_POLLS 180 → 300 = 10 分钟)
2. BlockNoteSummaryView 加 status=completed 主动 force reload effect,
   配 lastLoadedMarkdownRef 防无限循环.

### 改动
- `frontend/src/components/Sidebar/SidebarProvider.tsx:201, 273` 间隔改 2s, 上限 300
- `frontend/src/components/AISummary/BlockNoteSummaryView.tsx` 加 lastLoadedMarkdownRef +
  status=completed 触发的 replaceBlocks effect
