## 关键发现: 后端 API 不识别 sherpa provider

**新 binary (01:17 旧版) 启动日志**:
```
[01:59:58] Found transcript config: provider=sherpa_funasr_nano, model=sense-voice-zh-int8
[01:59:58] ERROR Failed to get transcript API key for provider sherpa_funasr_nano: 
           encountered unexpected or invalid data: Invalid provider: sherpa_funasr_nano
```

**根因**: `src-tauri/src/database/repositories/setting.rs` 的 `get_transcript_api_key` / `save_transcript_api_key` match 块只认识 `localWhisper / parakeet / deepgram / elevenLabs / groq / openai`, **不识别 sherpa_paraformer / sherpa_funasr_nano**。

**修复** (`setting.rs` 两个函数):
```rust
// Sherpa / Parakeet are local models, no API key needed
if matches!(provider, "parakeet" | "sherpa_paraformer" | "sherpa_funasr_nano") {
    return Ok(());  // save
    // 或 return Ok(None);  // get
}
```

**新 binary 02:02 重启后**:
```
[02:03:19] Found transcript config: provider=sherpa_funasr_nano, model=sense-voice-zh-int8
[02:03:19] Successfully retrieved transcript config and API key.    ← 错误消失
```
