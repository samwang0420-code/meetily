# 离线会记 迭代清单 v1.0 (2026-07-30)

> 本文是 **post-release 迭代 backlog**, 按用户 7/30 §31 P2 决定.
> 上架 v0.7.0 不阻塞这些, 但 2-3 个月后必须有进度.

## P0 (上架后 1-2 周必须做)

### 1. LLM Streaming 流式输出 (§31 P2 #1)
**为什么 P0**: 用户反馈"2 min 等待太长, 看着像卡了", 律师/医生群体尤其敏感 (30+ min 转录 + 摘要体感差).

**改动**:
- 摘要 SSE 协议: 服务端 `text/event-stream`, 客户端 EventSource
- llama-cpp / Ollama 端: 切 streaming mode (已有, 仅是 wrapper 接出)
- 客户端 useSummaryGeneration 加 `partial` state, 边收边渲染 (类似 ChatGPT 打字效果)
- partial → final 一致性: streaming 中途断网时, partial 缓存到本地, 重连后接续

**风险**:
- streaming token 截断 (最后一 token 不完整) — 加 final flush 检测
- partial 结果被误用: UI 必须明确标"草稿, 未完成"
- 中断恢复: localStorage 缓存 partial, 重连后 delta 增量

**估时**: 3-5 天
**验收**: 30 min 录音 + 生成摘要 → 用户第 3s 看到第 1 段 partial, 全文 60s 内边出边渲

### 2. 多语言 ASR UI (§31 P2 #2)
**为什么 P0**: 用户已明示"中英文要覆盖到", 现在 sensevoice auto 已支持 zh+en+yue+ja, 缺 UI 切换.

**改动**:
- TranscriptSettings 加 "语言" 下拉 (zh / en / yue / ja / auto)
- 持久化到 api_save_transcript_config 的 `language` 字段 (DB schema 已有)
- 录音实时显示当前语言
- 摘要自动用 transcript language (避免 zh 会议出 en 摘要)

**估时**: 1 天
**验收**: 选 en → 英文会议识别正确 (用英文测试音频); 切回 zh → 中文会议正常

## P1 (上架后 1-2 月)

### 3. 拍脸车 / 微信 / USDT 支付集成 (§18 C8-C10)
**为什么 P1**: 内测期走激活码 + 付邮够用, 但放量后必须自服务支付.

**改动**:
- 拍脸车 API: 国内小商户聚合, 微信 + 支付宝
- USDT TRC-20: 国际用户
- 后端 `/api/order/create` + `/api/order/webhook` + DB orders 表
- 前端 /redeem 加"购买激活码"按钮

**估时**: 5-7 天
**风险**: 拍脸车 / 微信支付都需要商户资质 (营业执照), 用户需先申请

### 4. ICP 备案 + 软件著作权 (§18)
**为什么 P1**: 商业化前必须, 国内上架 + 微信支付强制要求.

**估时**: 1-2 月 (申请周期)
**风险**: ICP 域名需备案, 主体需企业 (不能个人)
