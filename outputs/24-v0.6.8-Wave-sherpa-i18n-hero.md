## 关键技术修复

### 1. engine.rs sherpa 分支
```rust
// 旧 (编译失败)
"sherpa_paraformer" | "sherpa_funasr_nano" => {
    info!("...{}", other);  // other 未绑定
}

// 新
provider @ ("sherpa_paraformer" | "sherpa_funasr_nano") => {
    info!("...{}", provider);  // 用 @ 绑定
}
```

### 2. i18n 字典 errors 块结构
原 errors 块内容散在顶层 (没有 errors 包裹), 必须把散内容包进 errors.

### 3. PermissionWarning 三元
错: `{!a ? {t('X')} : {t('Y')}}`  对: `{!a ? t('X') : t('Y')}`

### 4. RecordingSettings 嵌套花括号
错: `{x || '{t(\"y\")}'}`  对: `{x || t('y')}`

### 5. 缺 useTranslation
AudioBackendSelector/BetaSettings/BuiltInModelManager/SummaryLanguageSettings 之前没用 t(), 加 useTranslation hook
