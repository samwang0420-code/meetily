# §186.1 v2 — auto-rename 错标 role label (不只标记)

**commit**: `3768e03` (codex/accuracy-experiment, pushed 2026-08-27)
**触发**: 用户 8/27 反馈 "为什么只是标记, 为什么不直接解决问题呢"

## 问题

§186.1 之前只插入 `⚠️[§186冲突(...)]` 标记, 用户还需自己读上下文判断哪个对哪个错. 用户要的是**直接重命名错标的 role label**, 不只警告.

## 修复 (3 个核心改动)

### 1. 搜整行 `**role**:` 完整模式 (含 closing `**` + 冒号)

之前 prefix 切片方案:
- `prefix_len` = 6 (在 `* **原告` 之后, `**:` 之前)
- `prefix` = `* **原告` (无 closing `**`)
- `after` = `**: 温明仁...` (含 closing `**` + 冒号)
- replace `**原告` with `**⚠️ §186.1 错标...:` → 产生 `* **⚠️...:**:` 双重冒号 BUG

新方案:
- 直接搜整行 `**role**:` 模式 (含 closing `**` + 冒号)
- replace 为 `**⚠️ §186.1 错标 (transcript 实为 X)**:` 完整结构
- 一次替换, 干净

### 2. 角色顺序: 长 token 先

```rust
for role_word in &["被告 1", "被告 2", "被告 3", "被告一", "被告二", "被告三",
                    "被告1", "被告2", "被告3", "被告",
                    "上诉人", "被上诉人", "原告", "死者", "证人", "辩护人", "公诉人"] {
```

- `被告 1` 先于 `被告` → 防短词抢匹配
- `**被告 1**:` 被正确替换为 `**⚠️ §186.1 错标...**:` (而非 `**⚠️ §186.1 错标...:**` 中混入 "1" 残字)

### 3. Fallback: 无 `**` 角色

`* 原告: 温明仁` (无 markdown bold):
- 整行搜 `**原告**:` 失败
- fallback 找 prefix 内 `原告` 位置, replace 为 `**⚠️...:**`
- prefix 剩 `* ` + warning + `:温明仁` = 干净

## 优先级 (correct_role_label)

```rust
if name_matches(&party, &ext_defendants) { "被告" }

```

## 铁律

1. **auto-rename 不是 auto-delete** — 保留原文 party name, 只改 role label. 用户看完整上下文, ⚠️ 显眼
2. **搜整行 `**role**:` 不用 prefix 切片** — closing `**` + 冒号必须 in pattern, 否则双重冒号
3. **长 token 先匹配** — `被告 1` > `被告` 防止短词抢匹配
4. **fallback 处理无 bold 角色** — `* 原告: X` 也能 rename
5. **保留所有 fixed_lines 报告** — `AUTO-RENAMED (X → Y, reason)` 进 fix_report
