## 八、FAQ

### Q1:真的 100% 离线吗?

A:是。CSP 已禁止所有外联,代码层无 fetch / WebSocket / XHR 调外部 API。
录音 → 转录 → 存储全在本地完成,关闭网络也能用。

### Q2:中文识别准确率多少?

A:安静环境普通话 95%+,中英混排 90%+。
带方言 / 多人抢话 / 远场场景会下降,建议配合人工校对。

### Q3:和飞书妙记比有什么优势?

A:数据本地(飞书云端)+ 价格便宜(¥39 vs ¥99)+ macOS 原生体验。
劣势:实时字幕 / 多设备同步 / 协作分享没有。

### Q4:支持哪些会议软件?

A:目前是麦克风录音(系统内录需 macOS 14+ 系统权限)。
Zoom / Teams / 微信语音通话通过麦克风采集,无需额外集成。
直接对接会议软件 API 在 v1.x 路线图。

### Q5:数据存在哪里?能导出吗?

A:`~/Library/Application Support/cn.lixianhuiji.app/meeting_minutes.sqlite`
随时可导出 Markdown / TXT(v0.2.0+ 支持 PDF / Word)。

### Q6:能退款吗?

A:订阅 7 天内未重度使用可全额退款,联系客服。
买断版 30 天内未重度使用可退款。

### Q7:团队版怎么收费?

A:¥99/月 最多 5 个席位,超 1 人 +¥20/月。
按席位算,不按设备数。

### Q8:有学生 / 教育优惠吗?

## 十、技术细节(FAQ 后续,可选)

### Q9:用的是什么模型?

A:默认 SenseVoice-zh(阿里达摩院开源,中文 SOTA)。
可选 Whisper Large-v3(multilingual)。
用户可在设置页切换,模型下载到本地,一次性 200MB-1.5GB。

### Q10:Python 依赖怎么管理?

A:内置 Python 3.10 + sherpa-onnx wheel,无需用户装 Python 环境。

### Q11:开源吗?

A:核心转录基于上游 Meetily(开源 fork)。
我们 fork 后做的离线化 + 中文优化不开源(商业护城河)。

### Q12:为什么不开源?

A:三条:
1. 商业模型本身需要差异化(本地化 + 中文 + 离线)
2. 开源后用户不会付费(尤其国内)
3. 客服和文档成本高,开源项目难持续

如果将来要做社区版(免费 + 开源) vs Pro 版(付费 + 闭源) 双轨,会考虑。
