## 6. 防再漏系统 (本节 P0 交付)

### 6.1 `scripts/audit_codebase.py` (新)

**职责**: 每次 commit 前跑一次, 全面扫描以下问题:

1. **死代码扫描**: `*.backup` / `*.orig` / `*_old.*` / `lib_old_complex*` / `core-old*` 在 src/ 下
2. **孤儿模块扫描**: 找 `pub mod xxx;` 但 lib.rs 没注册 (audio_v2 是例子)
3. **悬空命令扫描**: 前端 invoke('cmd') 但后端 invoke_handler 没注册
4. **孤儿命令扫描**: 后端 invoke_handler 注册但前端无 invoke('cmd') 调用
5. **版本号一致性**: tauri.conf.json / package.json / Cargo.toml / .app Info.plist 4 处 version 对齐
6. **identifier 一致性**: tauri.conf.json identifier vs .app CFBundleIdentifier
7. **v0.8.5 残留**: frontend/src 下 5+ 个 v0.8.5 字符串
8. **git ls-files backup/orig**: 任何 .backup/.orig/_old 文件不能进 git

### 6.2 `scripts/pre_release_check.sh` (新)

**职责**: release 前硬闸门, 顺序跑:

```bash
1. python3 scripts/check_historical_fixes.py --strict  # guard 76/76
2. python3 scripts/audit_codebase.py --strict         # §94 audit
3. cargo test --lib -- --skip audio::system_audio_*  # 326+/326+
4. cd frontend && pnpm run build                       # Next.js OK
5. cd frontend/src-tauri && cargo build --release      # Tauri OK
6. ./scripts/sync_app_bundle.sh                        # .app 同步
7. open '言镜 AI.app'  # GUI 验证
```
