# 离线会记项目总状态（2026-07-20）

## 一页结论

**产品主体已完成，当前不是继续堆功能，而是等你在真实 macOS App 里做最后验收。**

现阶段已经具备：本地录音、本地中文转写、摘要、法律/医疗模板、热词、说话人分离、导出、登录、免费配额、Pro 激活码和定价页。自动化与浏览器测试已经通过，但 **CLI 和浏览器测试不能替代真实 Tauri GUI 验收**。

本机数据库当前有 **41 场会议、272 段转写、12 条摘要流程记录、1 个用户、5 个激活码**。说明产品已有真实使用数据，不需要为了普通功能测试重新录音；只有 ASR 底层改动才需要 30 秒实录。

## 当前还存在的风险和不一致

1. **真实 GUI 最终验收还没有明确完成。** 自动化通过不等于 macOS Tauri App 真机通过。
2. **版本号不统一。** 项目记录写到 v0.6.21，但代码仓库中的 `package.json` / `Cargo.toml` 仍显示 0.4.0，`tauri.conf.json` 仍显示 0.1.0；发布前必须统一。
3. **代码仓库当前不是干净状态。** `frontend/src/hooks/useRecordingStop.ts` 有一个仅缺少文件末尾换行的未提交修改。
4. **大量后续功能存在于工作区而非清晰 Git 提交历史。** 当前分支最近正式提交仍主要是 W1 改造，发布前要整理、提交并建立可回滚版本点。
5. **数据库里有 41 场会议，但其中至少 1 场为 0 段。** 不能仅凭总量判断每次 ASR 都成功；底层 ASR 每次改动仍必须做真 GUI 实录回归。
6. **商业化有“激活码闭环”，没有“自动收款闭环”。** 现在适合内测和人工卖，不适合大规模自动销售。

## 等你做什么

### P0：现在只需要你完成这次最终验收

1. **完全退出 App（Cmd+Q），重新双击启动。**
2. **打开一条已有的真实会议，不需要重新录音。** 推荐直接用已有 26 段或 31 段的法律会议。
3. **选择法律模板，点击“重新生成摘要”。**
4. **确认摘要最终只显示 5 段新模板**：基本事实、当事人主张、律师建议、待办事项、遗留问题。
5. **确认没有三个故障**：React #321 红屏、摘要一直卡住、必须切走再切回才显示。
6. **确认摘要明显比旧 9 段版本短，且未提及内容没有被编造。**
7. **把结果告诉我即可**：通过；或发一张失败截图/错误文本。

### 只有涉及 ASR 底层改动时才需要你做

- 重新录制 30 秒中文。
- 停止后确认至少生成 1 段转写。
- 再由我查询 SQLite 段数确认，不允许只凭界面判断。

这次项目状态盘点本身没有改 ASR，所以**现在不要求你重新录音**。
