# v0.6.10 品牌位迁移 + 录音模型 fix + chip 文案 (2026-07-10)

## 用户反馈
1. **录音报错**: `Transcription failed: ... sherpa error: no installed model for tag 'sensevoice-zh-int8'. installed: ['paraformer-zh', 'sensevoice-zh']`
2. **品牌字位置反了**: Topbar 显示"离线会记 / v0.6.10", 侧栏只有盾. 用户要 **品牌字留侧栏, Topbar 只留盾**
3. **"转录模型 未选择模型"**: model chip 没识别当前 provider

## 改动

### Bug Fix 1: sherpa model tag 默认值错误

`frontend/src/contexts/ConfigContext.tsx:111-113` 默认值:
```ts
provider: 'sherpa_funasr_nano',
model: 'sense-voice-zh-int8',       // ← 安装包里没这个 tag
```

改为:
```ts
provider: 'sherpa_funasr_nano',
model: 'sensevoice-zh',             // ← 与 daemon 'installed' 列表对齐
```

### Bug Fix 2: sherpa_asr alias 不够宽松

`frontend/src-tauri/scripts/sherpa_asr.py:140` alias 只匹配 `sensevoice-zh` 一个值, 任何 tag 拼错都报 "no installed model". 加更宽的 alias + 最终 fallback:

```python
sensevoice_aliases = {
    "sensevoice-zh", "sensevoice-zh-int8",
    "sense-voice-zh", "sense-voice-zh-int8",
}
if tag in sensevoice_aliases:
    for t, i in models.items():
        if i["kind"] == "sensevoice":
            info = i; tag = t; break
if info is None:
    # 最终 fallback: 任何已装模型 (e.g. paraformer)
    for t, i in models.items():
        info = i; tag = t; break
```

### Bug Fix 3: HomeDashboard modelLabel 缺 `sherpa_funasr_nano` 映射

`frontend/src/app/_components/HomeDashboard.tsx:41` `modelLabel()` 加:
```ts
if (provider === 'sherpa_funasr_nano') return 'SenseVoice 实时';
```

之前缺这条分支, 默认返回 '未选择模型'.

### UI Fix: 品牌字迁移到侧栏

按用户原话: "两个离线会记 Logo 只保留左边那个, 离线会记 V0.6.10 这几个字都放到左边"
- 之前: 文字在 Topbar
- 修正后: **文字在 Sidebar 顶部 brand block**

#### `Sidebar/index.tsx`
