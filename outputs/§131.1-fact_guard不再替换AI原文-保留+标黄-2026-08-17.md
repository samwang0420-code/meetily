# §131.1 fact_guard 不再替换 AI 原文 — 保留 + fabricated tokens 标黄 (2026-08-17)

## 触发

§131 上一轮修了"单 fabricated number 阈值"问题, 用户反馈还是不对:

> 不是啊，你没看内容吗，

### 2. `fact_guard.rs::highlight_unexpected_facts()` — fabricated tokens 标黄

```rust
/// §131.1: 在 AI 摘要原文里把 fabricated 数字/日期标黄
/// 用 markdown `==text==` 黄色 highlight 包裹 fabricated tokens
pub fn highlight_unexpected_facts(summary: &str, report: &FactGuardReport) -> String {
    if !report.needs_review() { return summary.to_string(); }
    let mut out = summary.to_string();
    for token in report.unexpected_numbers.iter().chain(report.unexpected_dates.iter()) {
        if token.is_empty() { continue; }
        let marked = format!("==⚠️{}⚠️==", token);
        out = out.replace(token, &marked);
    }
    out
}
```

例: AI 原文 "实际佣金 9.29 千" → 渲染时 "实际佣金 ==⚠️9.29千⚠️==" (黄色背景)
