## 错误原文

```
error: failed to run custom build command for `cidre v0.11.3`
xcode-select: error: tool 'xcodebuild' requires Xcode, but active developer
directory '/Library/Developer/CommandLineTools' is a command line tools instance
```

## 为什么必须装 Xcode

`cidre` = **macOS 私有 framework 绑定库**(用于 ScreenCaptureKit / CoreAudio 系统音频捕获)
- Meetily 7 个 macOS 平台文件全部依赖它
- `build.rs` 调 `xcodebuild` 拿 macOS SDK 路径
- **没 Xcode = Mac 端无法录系统声音**(只能录麦克风)
- **没有绕过方案**(`xcode-select --install` 装的是 CLT,不够)

## Xcode 装机指南(Mac App Store)

### 步骤 1: 打开 Mac App Store
点 Dock 上的  App Store 图标

### 步骤 2: 搜 "Xcode"
搜索栏输入 `Xcode`,找到 **Xcode** (蓝色图标,Apple 出品,**不是** Xcode Cloud / Xcode Previews)

### 步骤 3: 点 "获取" / "安装"
- 大小:**8-15 GB**(看你网速)
- 时间:**30-60 分钟**(光纤)/ **2-3 小时**(普通宽带)
- **必须保持 Mac 唤醒**(设置 → 电池 → 防止自动睡眠,或接电源)

### 步骤 4: 装完首次启动(必需)
打开 Xcode,会弹窗要求"安装 additional components",**必须装**(约 5-10 分钟)

### 步骤 5: 切到完整 Xcode(关键)
打开 终端 跑:
```bash
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
xcodebuild -version   # 应该显示 Xcode 版本
```

**必须看到版本号**(如 `Xcode 26.0`)才算装好。

### 步骤 6: 接受许可协议
```bash
sudo xcodebuild -license accept
```

## 你的 Mac 是 macOS 26.5.1(超新)

警告:**Xcode 26 stable 可能还没出对应版本**。
- 如果 App Store 只显示 Xcode 16/17 → 装那个即可,meetily 要求 macOS 14.2+,Xcode 16+ 都支持
- 如果 App Store 完全搜不到 Xcode → 临时方案:用 `xcode-select` 指向另一个位置
- macOS 26 还在早期,**Meetily 在新 macOS 上可能需要小修**(遇到 panic 贴给我)

## 其他可能需要装的(看 build 报什么)

如果 `cargo check` 报缺这些,装就行。
