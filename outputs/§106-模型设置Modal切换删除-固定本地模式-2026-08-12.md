# §106 模型设置 Modal 切换功能删除 — 固定本地模式 (2026-08-12)

## 触发

用户 8/12 截图反馈:
> "这里的切换功能先仅用掉吧, 我们只用本地模型生成摘要"

模型设置 Modal 中 "AI 总结模型" 下拉让用户在 Built-in AI / Claude / OpenAI / Groq / Ollama / OpenRouter / Custom Server 间切换, 但项目宪法是"云端 API 永不接入"(§18, §71 §P0-P2 范围), 留这个 dropdown 是"华而不实"且误导用户(看起来支持云端但实际跑不通)。

## 改动 (3 文件, +11/-133)

### 1. `frontend/src/components/ModelSettingsModal.tsx` (-130/+8)

**删除** (137 行):
- 整个 `<Select>` provider dropdown (含 7 个 SelectItem)
- 下游 `<Popover>` + `<Command>` model combobox (含 loading 态、search、4 个 isLoading state)

**新增** (8 行静态展示):

{/* §106: 切换功能先仅用掉, 固定只用本地 (Built-in AI) 生成摘要 */}

视觉: 绿点 + 文字 + 右侧"已锁定本地模式 (云端服务暂不开放)" 标签。
不再有交互控件, 用户无法切换 provider (符合 §106 意图)。

## 设计意图

1. **§18 不主动改无关 bug** 精神 — 不删 JSX 块外逻辑, 只删用户能看见的"华而不实"控件
2. **§104 "华而不实" 用户原则延续** — 用户单一 PC 本地使用者, 一天 < 5 会议, 不会用云端
3. **隐藏 ≠ 删除** — git log 还原 1 行 + Select 块即可恢复 (rollback 风险 0)
4. **绿色实心点 + 静态标签** 视觉告诉用户 "系统已替你做了选择", 不会引发"我能切吗"的疑问
