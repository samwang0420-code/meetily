### B. 主 prompt 三条强制规则

在 `EVIDENCE_GROUNDED_SUMMARY_RULES` 增加:

```text
§131.3 UNIT CONFUSION RULE — MANDATORY:
12. UNITS ARE NOT INTERCHANGEABLE. If transcript mentions weight/volume (克/公斤/千克/毫升/升),
    you MUST NOT present those values as monetary amounts (元/块/美元).
    Conversely, money (元/块/美元) MUST NOT appear as weight/volume.
    - Example bad: source "可卡因9千多克" → "9.29千" as money
    - Example good: "9,277.27 克" verbatim OR "Weight/Amount: Not specified"

§131.3 TEMPLATE-CONTENT FIT RULE — MANDATORY:
13. If template asks for fields the source content does not support (e.g., "律师建议" in court,
    "客户需求" in monologue, "Next Steps" in retrospective), DO NOT fabricate.
    Write "本次无相关 [section 名]" verbatim. NEVER generate fictional lawyers/customers.

§131.3 EVIDENCE CITATION FORMAT — MANDATORY:
14. If you cite `[证据: mm:ss]` or `[mm:ss]`, the mm:ss MUST be derivable from a real
    transcript segment. DO NOT invent markers like `[evidence:71]` or `[00:71]` for
    content without timestamp grounding.
```

旧 "conservative fallback" 文案更新为 "marked for human review"。
