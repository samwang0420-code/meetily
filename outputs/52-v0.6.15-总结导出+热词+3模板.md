```rust

match SherpaStreamSession::begin(&model_name, hw_pack, hw_custom).await { ... }
```

## 边界 / 已知

- **3 个新模板 instruction 写的是英文** — LLM(qwen2.5/llama3.2 中文模型)能理解英文 instruction,但**最理想是中文 prompt**。如果用户反馈中文摘要质量差,加中文模板。
- **热词对原音错得太离谱的词无效**(如 "Rust" TTS 念成"如斯特"识别成"如斯特",fuzzy 找不到匹配)——热词救"近似音",救不了"识别错音"。
- **前端 UI 在会议详情页顶部新增的 2 个按钮是 conditional 渲染**(`{onExportMarkdown && ...}`),需要 PageContent 传 handler 才显示。已传,应可见。
