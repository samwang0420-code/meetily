## 故障排查

### 排查 1: 启动脚本说 ❌ Ollama 启动失败

```bash
# 看日志
cat /tmp/ollama.log | tail -20
# 手动启
/opt/homebrew/opt/ollama/bin/ollama serve
# 看进程
ps aux | grep ollama | grep -v grep
```

### 排查 2: 转录不是中文(乱码 / 英文)

数据库默认 provider 改了,可能要重启 meetily 让新配置生效:

```bash
pkill -f "target/debug/meetily"
sleep 2
/Users/wangwei/Documents/meetily/target/debug/meetily &
sleep 5
```

### 排查 3: 摘要卡住 / 报错

```bash
# 看 ollama 跑没
curl -sL http://localhost:11434/api/version
# 看模型在不在
ollama list
# 手动测摘要(代替 meetily 调)
curl -X POST http://localhost:11434/api/generate -d '{
  "model":"qwen2.5:1.5b",
  "prompt":"用一句话介绍离线会记",
  "stream":false
}'
```

如果上面手动测都失败:重新拉模型

```bash
ollama pull qwen2.5:1.5b
```

### 排查 4: Whisper 模型丢了(我可能下错地方了)

```bash
ls -la "/Users/wangwei/Library/Application Support/cn.lixianhuiji.app/models/"
```

如果 `ggml-small.bin` 不在:跑

```bash
curl -sL --max-time 60 -o "/Users/wangwei/Library/Application Support/cn.lixianhuiji.app/models/ggml-small.bin" \
  "https://hf-mirror.com/ggerganov/whisper.cpp/resolve/main/ggml-small.bin"
```
