## 4. 铁律 (任何 v0.X 演进适用)

1. **新增 i18n key 必须同时写 zh.ts + en.ts** — 单边会被 verify_i18n.mjs 抓出
2. **新增使用 t() 的组件必须先 import { useTranslation }** — 不允许 "import 但未用" 状态 (§38 续)
3. **隐藏 Tab ≠ 删除 Tab** — `{false && ...}` 包装, 保留 import + 组件 (§117 风格)
4. **隐藏 i18n 块要先 grep 源头** — 用 `rg -i 'some English phrase'` 搜源码, 不要 grep 转译后 bundle
5. **bundle 验证要看 zh + en 都正常** — 中文渲染 + 英文 fallback 都要测
