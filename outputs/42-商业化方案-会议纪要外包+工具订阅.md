# 离线会记 · 商业化方案 v1.0(2026-07-16)

> **核心结论**:**先卖服务,后卖工具**。会议纪要外包服务是高客单价现金流,工具订阅是长线复利。两条路并行,但**前 3 个月只做服务**。

---

## 一、商业模式

### 主推:会议纪要外包服务

- **定位**:面向跨境电商 / SMM / 外贸工作室的"会议跟进 + 纪要整理"
- **客单价**:¥1500-3000/月 / 单工作室
- **交付**:每周 5-10 场会议 → 中文纪要 + 待办清单 + 跟进提醒
- **核心优势**:**我们自己用工具**(离线会记),效率是别人 3 倍,价格压到市场 50%

### 辅推:工具订阅(3 个月后启动)

- **标准版 ¥39/月**:无限时长 + 全部模型 + Markdown 导出
- **专业版 ¥99/月**:加 Whisper Large / 热词 / 批量导入
- **买断版 ¥299**:一次付费,永久使用,1 年更新

### 为什么不先推工具

- 个人订阅转化率 < 2%(国内用户习惯免费)
- 需要客服 / 持续运营,单人扛不住
- 工具功能还不完整(无批量导入、无热词 UI、无导出),不值得卖
- 服务反过来给工具提供真实反馈,帮迭代

## 二、销售话术(直接复制粘贴发群)

### 话术 A:SMM 群 · 软广版(不直接卖,讲故事)

```
最近帮 3 个跨境工作室做会议纪要,有个事挺有意思:

有个红人合作谈崩过 3 次,原因就是"会议上说的价,回去变卦"——
其实是中文转英文时把"底价 $800"听成"建议价 $1000"。

现在工作室每周开 5 场红人会,全用我提供的纪要:
- 中文转写(说话人识别)
- 关键数字 + 待办标黄
- 24h 内发回,直接发到老板邮箱

结果:3 个工作室 1 个月内 0 投诉,反而回头介绍 2 个新客户。

我没做什么神奇的事,就是用自己开发的纯离线工具 + 手工整理。
有兴趣的私聊,前 5 个工作室 8 折试用。
```

**为什么有效**:
- 没有"卖软件 / 服务"的直接推销,讲案例
- 痛点具体(跨境红人谈崩),目标用户秒懂
- "前 5 个 8 折"制造稀缺 + 紧迫
- 结尾"私聊"过滤低质用户

### 话术 B:朋友圈 / 公众号版

```
做跨境 / 外贸 / SMM 的朋友,问个问题:

你们团队每周开 3-5 场客户会议,会议纪要怎么出?

a) 让助理录音,听 3 倍速回放,手敲文字
b) 用飞书妙记 / 腾讯会议 AI,但客户对话数据上云
c) 让客户自己写纪要,结果 80% 没下文

我选了第 4 条路:自己写了个**纯离线**的转录工具,加上人工整理,
每周 5 场会议 → 24h 内出中文纪要 + 待办清单,发到老板邮箱。

纯离线 = 数据不上云,客户对话不被 AI 偷学
人工整理 = 关键数字 / 承诺 / 异议点全部标黄,直接能跟进

目前在帮 3 个工作室做这件事,效果还行。

前 5 个工作室 8 折试用,聊 5 分钟看看适不适合你。
```

**为什么有效**:
- "问个问题"开头,不让用户觉得是广告
- a/b/c 选项让用户对号入座
- "纯离线"差异化卖点前置
- 不主动定价,引导私聊

### 话术 C:小红书 / 知乎测评版

**标题**:`飞书妙记替代品?我测了 5 个 AI 会议工具,这个最干净`

**正文骨架**:
```
工作需要每周 5 场跨境客户会议,飞书妙记方便但数据上云让我有点慌。

先后测了:
- Otter.ai(英文为主,中文拉胯)
- 通义听悟(免费额度太抠,1 小时就没了)
- 飞书妙记(好用但要上传云)
- Whisper 桌面版(部署 3 小时放弃)
- 离线会记(国产,纯本地,中文 SenseVoice)

最后留下来的是 离线会记,因为:
1. 完全离线,会议录音不上传
2. 中文识别准(测试 10 段,9 段无错字)
3. 数据存本地 SQLite,自己能掌控
4. macOS 原生,体积 64MB

缺点:Windows 还没出 / 实时字幕还在调 / 没有会议纪要自动生成

适合:对客户隐私敏感 / 数据合规要求高 / 在 macOS 上的外贸/SMM/律师/医生

不推荐:企业全员部署 / 需要实时翻译 / 用 Windows

免费版 30 min/次,够个人用,我自己买的 Pro ¥39/月。
```

**为什么有效**:
- 测评体,不是广告,知乎/小红书用户爱看
- 提竞品(让用户知道你知道行业),不黑不吹
- 优缺点都说,真实感强,转化率反而高
- 主动定位"不适合谁",筛掉低质用户

### 话术 D:1v1 私聊开场(给准客户发)

```
[客户名字] 你好,我是 [你的名字],做 [跨境会议纪要 + 工具] 的。

在 [XX 群/朋友圈] 看到你提到 [客户的痛点,比如"红人合作经常谈崩"]。

我目前帮几个工作室做一件事:每周 5-10 场会议 → 中文纪要 + 待办 + 24h 交付,
纯本地处理,数据不上云。

不卖软件,直接卖服务:¥2000/月,前 5 个 8 折 ¥1600/月。

方便的话聊 5 分钟?不合适就当认识一下,不打扰。
```

**为什么有效**:
- 第一句点对方具体痛点(证明你看过他发言,不是群发)
- "不卖软件"打消警惕
- 给具体价格(避免来回拉扯)
- "不合适就当认识"降低对方压力

## 五、不做的事(红线)

- ❌ **不做企业全员部署**:交付重,客服累,单人扛不动
- ❌ **不接录音外包(纯转写无整理)**:客单价低,无法建立壁垒
- ❌ **不承诺"100% 准确"**:会议场景有方言 / 术语,工具 + 人工也只能 95%+
- ❌ **不接跨语言翻译会议**:中英混排还在调,接了等于砸招牌
- ❌ **不卖数据**:哪怕给钱也不卖,这是底线
- ❌ **不接黄赌毒 / 政治 / 涉政**:永久封号
