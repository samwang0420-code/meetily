> **核心**: main 永远是 release-ready, feature 分支从 main 出, 合并后自动删, 旧分支保留 24h 观察期.

## 1. 新 Git workflow (v0.8.7+ 适用)

### 1.1 铁律

1. **新版本从 main 开新分支** — 不再从旧 feature 分支累积
2. **合并后自动删除源分支** — `git push origin --delete <branch>`
3. **旧分支保留 24h 观察期** — 打 `cleanup-recommended-<date>` tag 提醒
4. **main 永远是 release-ready** — 不允许"长期 feature"堆积在 main 之外

### 1.2 标准流程

```bash
# 1. 新版本开发
git checkout main
git pull origin main
git checkout -b feature/v0.8.7-xxx

# 2. 开发 + 测试 + commit (§37 6 步闸门)
# ...

# 3. 准备合并 (24h 前)
git push origin feature/v0.8.7-xxx
gh pr create --base main --head feature/v0.8.7-xxx

# 4. 在 GitHub 网页 squash merge

# 5. 合并后: 立即清理源分支
git push origin --delete feature/v0.8.7-xxx
git branch -d feature/v0.8.7-xxx

# 6. 24h 后清理 main HEAD (本地 + 远端)
git checkout main
git pull origin main
```

### 1.3 旧分支保留机制

合并后的分支**保留 24h** 用于回滚。打 tag 标记：

```bash
# 合并后立刻
git tag -f cleanup-recommended-$(date +%Y-%m-%d) <branch-commit-sha>
git push origin --delete <branch>
git tag -d cleanup-recommended-<date>  # 本地 tag 也保留, 防止误删
```

**24h 后自动清理**（不需要手动，等下次 session 起手时检查）：

```bash
# 下次 session 起手:
branches=$(git ls-remote origin | awk '{print $2}' | grep -E "backup|perf|feature" | head -20)
for b in $branches; do
  # 24h 前的清理提醒:
  if [ $(git tag -l "cleanup-recommended-*" | wc -l) -gt 0 ]; then
    echo "⚠️ 待清理旧分支: $(git tag -l 'cleanup-recommended-*')"
  fi
done
```

## 5. 24h 后清理脚本 (`scripts/cleanup_old_branches.sh`)

```bash
#!/usr/bin/env bash
# §115: 24h 自动清理机制
# 任何 (merge_deprecated_* / cleanup_recommended_*) 备份 / 旧分支默认 24h 后删

set -euo pipefail
cd "$(git rev-parse --show-toplevel)"

# 列出所有远端待清理分支
TARGETS=$(git ls-remote origin | awk '{print $2}' | grep -E '(backup/|cleanup|merge_deprecated)' | sed 's|refs/heads/||')

for b in $TARGETS; do
  echo "Cleanup candidate: $b"
  # 检查 tag 时间
  if git ls-remote origin | grep -q "refs/tags/cleanup-recommended.*"; then
    echo "  → Has cleanup-recommended tag, safe to delete"
    git push origin --delete "$b" 2>&1 || echo "  → Delete failed (skip)"
  fi
done

# 检查 perf/* / feature/* 旧分支 (用 last commit date 判断)
for b in $(git branch -r | grep -E "(perf/|feature/)" | tr -d ' '); do
  LAST=$(git log -1 --format=%ct "$b" 2>/dev/null || echo 0)
  NOW=$(date +%s)
  AGE_HOURS=$(( (NOW - LAST) / 3600 ))
  if [ "$AGE_HOURS" -gt 24 ]; then
    echo "Old branch (>24h): $b (last commit ${AGE_HOURS}h ago)"
    # 删除前提示
    if [ -n "$1" ]; then
      git push origin --delete "$b" 2>&1 || echo "  → Delete failed"
    fi
  fi
done
```

**使用**:
```bash
# 检查 (dry-run)
bash scripts/cleanup_old_branches.sh

# 实际清理 (参数)
bash scripts/cleanup_old_branches.sh --force
```
