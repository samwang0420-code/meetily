## 五、对商业化的影响评估

### 必修 (商业化前必须修) — 3 项
1. **P1-8 user_id 过滤** — 多用户机器/共享电脑立刻数据泄漏
2. **P1-9 delete_meeting user_id 校验** — 误删他人会议 (0 损失但破坏信任)
3. **P2-19 sherpa_asr.py + 热词进包** — release 用户用 app bundle 时, 流式 ASR / 法律医疗热词 直接 0 效果, 等于没做产品

### 推荐修 (营收/信任相关) — 3 项
4. **P1-10 API key Keychain** — 当前云端 API 模式已硬 gate (本地), 但本地模型 key 仍是明文
5. **P1-11 DB 0600** — 单机本地用户也能避免自己其他 app 读 DB
6. **P1-C.1 capabilities 单文件粒度** — `fs:scope` 应进一步限制到具体 SQLite / decode_cache 子目录

### 不修 (按 §18 不主动改 / 设计选择) — 4 项
- P1-12 密码 SHA-256 单轮 (本地单机 + 设计选择, 注释明示)
- P1-13 machine_id fallback (误读)
- P2-20 依赖升级 (技术债, §18)
- P1-7 hotwords UAF (无 unsafe 代码)
