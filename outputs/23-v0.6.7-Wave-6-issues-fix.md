- 派发 `lixianhuiji:toggle-recording` 自定义事件
- **bug**: 没人监听

- 之前是 `<button>` 派发 `lixianhuiji:open-command` 自定义事件
- **bug**: 没人监听, **不可点击输入**

**文件 C**: `src/components/Sidebar/index.tsx` — 加 listener

```ts
useEffect(() => {
  const recHandler = () => { handleRecordingToggle(); };
  const searchHandler = (e: Event) => {
    const q = (e as CustomEvent<string>).detail || '';
    setSearchQuery(q);
    if (q) searchTranscripts(q);
  };
  window.addEventListener('lixianhuiji:toggle-recording', recHandler);
  window.addEventListener('lixianhuiji:search-query', searchHandler);
  return () => { ... };
}, [handleRecordingToggle, searchTranscripts]);
```

**修复 CommandTrigger → 真正 input**:
- 改成 `<input type="text">`, 用户可输入
- 输入时 debounce 200ms 派发 `lixianhuiji:search-query` 事件
- Sidebar 监听, 调用 `searchTranscripts(q)` 真正搜索会议
- 加 X 按钮清空搜索
