## 实施

### 1. `frontend/src-tauri/scripts/convert_scel_to_json.py` (新, 299 行)

**功能**:
- 解析 .scel (搜狗拼音细胞词库格式) → (word, freq) 元组
- 跳过 0x200 字节 metadata 区
- UTF-16LE 中文字符连续提取
- 质量过滤:
  - 长度 3-10 字
  - ≥2 个汉字
  - 排除元数据污染词 (METADATA_BLACKLIST 14 个)
  - 排除 GBK 误解码乱码 (GARBAGE_CHARS 18 个)
- 多文件合并去重 (md5 hash)
- 同词保留最高频
- 按 freq 降序取 top N
- 写 hotwords_data/{pack_name}.json 格式 (同 §91 已有 pack schema)

**用法**:
```bash
python3 convert_scel_to_json.py \
  --input-dir /Users/wangwei/Documents/离线会记/热词 \
  --output-dir frontend/src-tauri/scripts/hotwords_data \
  --max-words 800 \
  --pack all
```

**预定义 pack 分类**:
```python
PACK_GROUPS = {
    "sogou_medical_curated": [9 个医学 .scel],
    "sogou_legal_curated": [6 个法律 .scel],
}
```
