### 1. 新函数 `inject_missing_required_statutes` (hard_post_process.rs)

```rust
pub fn inject_missing_required_statutes(md: &str, transcript: &str) -> (String, usize) {
    let report = check_statute_completeness(md, transcript);
    if !report.is_high_voltage_case || report.has_evidence {
        return (md.to_string(), 0);
    }
    let mut out = md.to_string();
    let high_voltage_statutes = vec![
        ("《中华人民共和国民法典》第一千二百四十条",
         "从事高空、高压、地下挖掘活动或者使用高速轨道运输工具造成他人损害的,经营者应当承担侵权责任 (现《民法典》高压致害无过错责任条款, 替代原《侵权责任法》第七十三条)。"),
        ("《中华人民共和国侵权责任法》第七十三条",
         "从事高空、高压、地下挖掘活动或者使用高速轨道运输工具造成他人损害的,经营者应当承担侵权责任 (现《民法典》第一千二百四十条前身)。"),
    ];
    let mut injected = 0;
    for (statute_name, statute_text) in &high_voltage_statutes {
        if out.contains(statute_name) {
            continue;
        }
        let statute_line = format!(
            "- **⚠️ §190.2 自动注入 (核心定责法条, 原 LLM 输出遗漏)**: **{}** — {}",
            statute_name, statute_text
        );
        // Insert into existing 法条引用块 or create new one
        ...
    }
    (out, injected)
}
```

**实际状态**: 我们已经是最优配置, 不需要换:

| 维度 | 实际状态 |
|---|---|
| 量化 | **Q4_K_M** (已经是 INT4 等效, 平均 4.5 bit) |
| 推理框架 | **llama.cpp** (llama-helper sidecar, 不是 transformers) |
| 硬件 | macOS **Metal GPU** 待启用 (目前纯 CPU) |
| 并发 | §64 A: 3 daemon 并行 (默认) |
| 优化链 | §52 max_tokens=800 / §53 chunk_text 中文标点 / §51 Map 2 路并发 / §64 A 3 daemon |

**真实可优化点**:
1. **启用 Metal GPU offload** — llama-helper 没启用 n_gpu_layers, 3B 在 M1/M2 Metal 上应该 50-80 tok/s vs CPU 30 tok/s, **关键优化** (用户没明示要求, §18 范围内待用户拍板)
2. **短文 skip Map** — <3000 chars 不分片, 单次推理 (用户建议), 当前 §51 默认 2 路并发 (实际串行)
3. **max_tokens per-model** — 3B 可放大到 1200, 2B 必须 ≤ 800 (§52 守卫)

**不推荐**:
- ❌ 换 transformers + bitsandbytes (我们没用 transformers)
- ❌ 换 ollama (我们用 llama.cpp, 一样的底层)
- ❌ 换其他模型 (qwen2.5:3b 已经是 SOTA 中文小模型之一)
