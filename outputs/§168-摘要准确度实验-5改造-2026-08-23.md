## 4. 各 § 改造要点

### §163 — 推理参数固化

```rust
// llama-helper/src/main.rs
let default_temperature: f32 = env::var("LLAMA_DEFAULT_TEMPERATURE").unwrap_or(0.1);
let default_top_p: f32 = env::var("LLAMA_DEFAULT_TOP_P").unwrap_or(0.3);
let default_repeat_penalty: f32 = env::var("LLAMA_DEFAULT_REPEAT_PENALTY").unwrap_or(1.05);
```

Qwen 3.5 2B 在 0.1/0.3/1.05 下输出稳定可预测, 显著减少幻觉 (温度 1.0 → 0.1 是从"自由发挥"到"事实压缩")。

### §164 — hard_post_process

两轮清洗:
1. **fix_mapping 正则替换** — 30+ 法律医疗常见错字对 (李富强→李福强, 刻碰致死→磕碰致死, 撒车→刹车 等)
2. **标准动词 fuzzy 归一** — 字符 Jaccard > 0.85 替换 (撞击/碾压/磕碰/切除/缝合 等)

边界检查: 单向后一字符 (同 last char) 阻止 (防嵌入), 前字符不阻止 (默认替换)。文档 `(?<![一-龥])X(?![一-龥])` 双向 lookbehind 实际过度严格, 简化为单向。

集成点: `processor.rs::generate_meeting_summary` 在 `clean_llm_markdown_output` 之后立即调用。

### §165 — 多案件 JSON 数组

新增 `fact_guard.rs::wrap_summary_as_multi_case_array(transcript, summary) -> Option<String>`:
- 检测到跨案件 → 返回 JSON 数组 `[{case_index:1, defendant:"三小", content:"<原 markdown>"}, {case_index:2, defendant:"赵某", content:"(待补)", warning:"..."}]`
- 否则 None (走原 markdown 路径)

UI 检测 `[` 开头 + `case_index` 字段 → 显示橙色多案件 banner。

### §166 — UI 标识

- `TranscriptPanel.tsx` 顶部: 浅灰底 + FileText icon + "原始转录 · 证据源" + 右侧 "只读" 徽章
- `SummaryPanel.tsx` 顶部: amber 边框 + 免责声明 (硬编码前端, 不依赖模型输出)
- 多案件 banner: 橙色 + data-testid

i18n 4 个 key (zh + en): `transcript_evidence_source` / `transcript_readonly` / `summary_disclaimer` / `multi_case_warning`。

### §167 — 科室会诊模板

`templates/medical_internal_round.json` 10 段:
1. 事实时间线 / Key Events Timeline
2. 整件事叙述 / Narrative Summary
3. 患者与会诊基本信息
4. 病史汇报与主诉
5. 体征与检验指标
6. 各医生意见汇总 (按医生分段, 禁止"专家共识"合并)
7. 会诊结论与下一步
8. PHI 警告头 (硬编码, 严禁上传云端)
9. 随访与预警事项
10. 待确认信息

注册到 `defaults.rs::get_builtin_template("medical_internal_round")`。
