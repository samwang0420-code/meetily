### Bug A · 17-47-40 重复段 (上一轮 listener 修复不完整)
**SQLite 状态**:
- DB: 2 条完全相同 (audio 0.45-73.2, length=426 字节, text 一字不差, timestamp 09:48:56)
- transcripts.json: 0 段 (`add_transcript_segment` 从未被调用)

**根因追溯**:
1. 上一轮修了 `add_transcript_segment` (Rust 端) 加 (start, end) 二次去重 ✓
2. **但前端 `setTranscripts` 只用 `sequence_id` 去重** (line 251)
3. 如果 Rust 端 emit 2 次, `SEQUENCE_COUNTER.fetch_add` 拿 0 + 1 (不同 seq)
4. 前端 listener 收到 2 次, `transcriptBuffer` 按 seq 去重 (因为 set 的是 `transcriptBuffer.set(update.sequence_id, ...)`)
5. **但 setTranscripts 路径走的是 processBufferedTranscripts 内的 prev.some(sequence_id match)**
6. **如果 prev 没有 0, 加 sequence_id=0 段; 下一轮 prev 有 0, 加 sequence_id=1 段 (新 seq, 不算 dup)**
7. 2 条不同 seq, 同 (start, end), 都进 transcriptsRef
8. useRecordingStop saveMeeting 把 transcriptsRef 2 条传给 `api_save_transcript`
9. DB INSERT 2 条 (新 uuid)

**修复 (前端)**:
- `frontend/src/contexts/TranscriptContext.tsx:251` setTranscripts 加 (start, end) ±50ms 二次去重 (同 add_transcript_segment)
- `frontend/src/contexts/TranscriptContext.tsx:445` addTranscript 同样加 (start, end) 二次去重 (替代旧的 text+timestamp 弱去重)

## 修复 (代码)

### Fix 1: 前端 setTranscripts 双层去重
`frontend/src/contexts/TranscriptContext.tsx:251-273`:
```typescript
const TIME_TOL = 0.05;
const isDup = (a: Transcript, t: Transcript) => {
  if (a.sequence_id !== undefined && t.sequence_id !== undefined && a.sequence_id === t.sequence_id) return true;
  if (a.audio_start_time !== undefined && t.audio_start_time !== undefined
      && a.audio_end_time !== undefined && t.audio_end_time !== undefined
      && Math.abs(a.audio_start_time - t.audio_start_time) < TIME_TOL
      && Math.abs(a.audio_end_time - t.audio_end_time) < TIME_TOL) return true;
  return false;
};
const uniqueNewTranscripts = allNewTranscripts.filter(t => !prev.some(p => isDup(p, t)));
```
