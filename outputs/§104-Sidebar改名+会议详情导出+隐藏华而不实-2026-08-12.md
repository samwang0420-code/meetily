## §104.1 录音通知 Toast 英文 → i18n (2026-08-12 11:45)

**触发**: 用户 8/12 截图反馈右下角弹出 "Recording Started / Inform all participants / Don't show this again / I've Notified Participants" 全部英文, 而主界面是中文.

**根因**: `frontend/src/lib/recordingNotification.tsx` 4 处硬编码英文, 没走 i18n. 该文件是 utility function (非 React 组件), 不能用 `useTranslation` hook.

**修复**:

1. `frontend/src/lib/recordingNotification.tsx`:
   - import `DICTS, Locale` from `@/i18n`
   - 加 `localT(path: string)` helper: 读 `localStorage['lixianhuiji.locale']` → 选 `DICTS.zh` / `DICTS.en` → 路径 lookup
   - 4 处硬编码替换:
     - `'🔴 Recording Started'` → `localT('recording.notification.title')`
     - `Inform all participants this meeting is being recorded.` → `localT('recording.notification.body')`
     - `Don't show this again` → `localT('recording.notification.dont_show')`
     - `I've Notified Participants` → `localT('recording.notification.ack')`

2. `frontend/src/i18n/locales/zh.ts` `topbar.recording` 块后加 4 个 key:
   ```ts
   recording: {
     title: '🔴 录音已开始',
     body: '请告知所有参会者, 本次会议正在被录制。',
     dont_show: '不再显示此提示',
     ack: '我已告知参会者',
   }
   ```

3. `frontend/src/i18n/locales/en.ts` 同步英文.
