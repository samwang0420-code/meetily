# §139 模板提示词商业化精进 (2026-08-19)

## 触发

用户 8/19 原话: "针对各种模板的提示词, 你站在商业化的角度, 再次精进"

## 核心目标

10 个摘要模板 (standard_meeting / daily_standup / project_sync / retrospective / legal_consultation / court_hearing / medical_consultation / psychatric_session / sales_marketing_client_call / cross_border_ecommerce) 从"可读"提升到"专业交付级",让客户拿到摘要可以直接转发给老板/律师/医生/合作伙伴,不需要二次加工。

## 1. §139 通用商业化硬约束 (5 条)

每个模板 timeline section instruction 末尾追加:

```
【§139 商业化硬约束 — 摘要必须达到专业交付级】
1. 零废话: 严禁'本文将/接下来/首先/其次'等空话. 严禁'TBD/待定/...'. 直接给事实和结论.
2. 零编造: 客户拿到摘要直接转发给老板/律师/医生/合作伙伴, 不能出 fact error. 不确定就写'信息不明确'.
3. 可追溯: 每个关键事实带 [证据: mm:ss] 转录时间戳, 客户按时间戳能直接跳到原始录音核对.
4. 专业语: 不用 LLM 风格 ('可能也许'/'总之'/'总的来说'). 用领域术语 (庭审用'法庭调查/举证质证', 医疗用'主诉/查体', 销售用'异议处理').
5. 可对比归档: 同一项目/客户/案件的多次会议摘要, 命名/人名/数据口径要一致, 便于跨会议纵向对比.
```

## 2. 10 模板定制商业化可交付级块 (新增 sections)

### standard_meeting (8 sections)
- **新增** "会议出席与缺席" — 列出转录中明确提到的发言者 + 角色 + 出席状态 + 决策权标注
- **升级** "关键决议" — item_format 加 `| 责任方 | 完成窗口` + 商业化要求 "客户拿到摘要可直接当'待办邮件'发出去"

### daily_standup (9 sections)
- **升级** "成员出席与状态" — 升级 instruction
- **新增** "阻塞项与升级需求 (P0/P1/P2)" — P0/P1/P2 优先级从转录紧急程度措辞推断,markdown table

### project_sync (12 sections)
- **升级** "里程碑与状态" — item_format 升级 (含责任方+关联文档)
- **新增** "里程碑详细状态表" — 表格: 状态/计划完成/实际完成/责任人/阻塞项/进度百分比 (verbatim 引用)
- **新增** "决策日志" — 决议序号 + 提出人 + 讨论摘要 + 共识依据 + 关联决议

### retrospective (8 sections)

- **新增** "行动项测量指标" — 表格: 衡量指标/目标值/当前基线/下次验收时间 (必须可量化)

### legal_consultation (9 sections)

- **新增** "证据清单 + 文件清单" — 表格: 文件名/版本日期/来源/关联主张/可用性

### court_hearing (10 sections)

### sales_marketing_client_call (12 sections)
