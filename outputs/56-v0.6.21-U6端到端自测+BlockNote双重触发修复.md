## 真实测试发现的新 Bug

U_v6_real_e2e.cjs 用 React TestRenderer 真实组件挂载, 模拟完整生命周期,
跑出来一个生产代码未覆盖的边界:

**场景**: 用户已经看到一次摘要 (status=completed), 然后切走再切回,
父组件传**新 markdown 对象**但 status 仍停在 `completed`。

**Round 2 修复** (status-only effect) **不触发** — 因为 status 没变。
U6-C 测试 `BlockNote mock: 新 markdown 触发第二次 replace` 直接抓到。

**修法**: effect 依赖 `[status, data?.markdown, editor, format]`,
status 变化 OR markdown 引用变化都触发, 用 `${len}:${prefix64}` 做去重 key 防循环。
