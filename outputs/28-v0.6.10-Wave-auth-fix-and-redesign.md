# v0.6.10 登录注册彻底修复 + UI 重设计 (2026-07-10)

## 用户反馈
1. **登陆注册流程需要调试通, 现在还是失败的**
2. 页面太素, 需与整体风格一致, 要有审美

## 根因 (Bug 锁定)

`frontend/src-tauri/src/lib.rs` **`.manage()` 漏注册 SessionStore**:

```rust
#[tauri::command]
pub async fn user_register(
    sessions: tauri::State<'_, SessionStore>,   // ← 注入失败
    ...
)
```

`tauri::State<'_, SessionStore>` 在 invoke 时找不到 manage'd session, **Tauri 抛 StateNotFoundError → invoke 抛 Err 到前端** → 前端 catch 块返回 `errToMessage('registration_failed')` → UI 显示 **"注册失败"** —— 但其实是 state 管理 bug, 不是用户输入的问题。

`commands.rs` 写了完整 `SessionStore` + `Mutex<HashMap<String, i64>>`, 但 `lib.rs` 没 `use` + 没 `.manage()` — 注册/登录全链路看似完整, 实际首次 click 就 panic 在 state lookup 阶段。
