## 关键技术决策
1. **Cloudflare Pages 静态站** — 免费, 1-2 分钟全球生效, 自动 HTTPS
2. **DMG 3 分卷** — Pages 单文件 25 MiB 上限, 用 `split -b 24m` 拆 + 提供合并命令 (sha256 验证)
3. **R2 暂不启用** — Token 无 R2 权限, Dashboard 手动 enable 后可考虑切换
4. **Zone DNS Edit 缺权限** — Token 没 Zone DNS Edit, custom domain 绑定后需用户去 Dashboard 加 2 条 CNAME (`@` 和 `www` → `yanjingai-web.pages.dev`)
5. **JSON-LD** — 首页含 Organization / WebSite / SoftwareApplication 3 个 schema, FAQ 页含 FAQPage, 价格页含 Product
6. **llms.txt + llms-full.txt** — GEO 标准, 给 AI 爬虫完整产品说明
7. **OG image** — 直接用 1024x1024 logo 放大到 1200, 后续可补 1200x630 定制版
