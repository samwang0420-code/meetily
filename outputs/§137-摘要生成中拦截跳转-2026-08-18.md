## 设计原则

### 拦截 3 层 (按触发频率排序)
1. **history.pushState/replaceState** (90% 场景) — 用户点 "返回工作台" 按钮 / Sidebar 链接 / Next.js Link / router.push
2. **popstate** (5% 场景) — 浏览器后退按钮 (⌘+[ / ⌫)
3. **beforeunload** (5% 场景) — 浏览器刷新 (⌘+R) / 关闭 / Tauri webview close

### 不破坏 Next.js
- 原始 `pushState` / `replaceState` 引用保存, 确认时再调
- 同一 pathname + search (query 变化) 放行, 不重复弹 modal
- useEffect cleanup 时还原, 组件卸载后 Next.js 正常工作

### 取消时回滚 url
- popstate 触发时浏览器已经改了 url, 用户取消要 push 回原 url, 否则用户感知"明明点取消, url 还是变了"
- 不用 `history.go(1)` (会循环), 用 `originalPushState` 推一个等价的空 state
