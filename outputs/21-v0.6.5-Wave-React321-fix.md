## 6. 已知边界

### 6.1 Tauri 二进制嵌入了 10:11 的 out/
- 修改任何 .tsx 文件 → 必须 `npm run build` (重打 out/) + `cargo build --release` (嵌入新 out) + 重启 binary
- 否则 binary 仍用旧 chunks

### 6.2 Recording cannot start 错误
- Rust 后端 `recording_commands.rs:101,347` 在模型未就绪时返回 `userMessage: "Recording cannot start..."`
- 这是**预期错误**,不是 #321 — 录音按钮点击链路正常
- 用户应到 Settings → Transcription 下载模型后再启动录音

### 6.3 Provider 'sherpa_funasr_nano' is not supported
- Rust 后端 `recording_commands.rs` 不接受 `sherpa_funasr_nano` 作为本地转录 provider
- 前端 `useRecordingStart.ts:159` toast 抛出
- 这是**配置问题**,用户需切换到 `localWhisper` 或 `parakeet`
